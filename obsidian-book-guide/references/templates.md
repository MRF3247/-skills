## 3. 拆分特殊情况命名规则

| 情况 | 处理 |
|------|------|
| 前后重复目录 | 分别保存为"前置目录""尾部目录"或"合集导航"，不静默删除 |
| 目录有章节、正文没有 | 不创建伪原文；在导读与知识全览中说明缺失 |
| 正文中途截断 | 文件名标记"残篇"，导读说明截断位置 |
| 中文版总序/推荐序/译后 | 独立成篇，不是作者正文；导读分层分析 |
| 源文件已有标题层级 | 原样保留，包括源内 H1；不为美观篡改 |
| 多卷本/合集 | 以册为最高有效章节文件，不建子文件夹；合集导航可单独成篇 |
