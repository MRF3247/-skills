# 浮出块配方 + 节拍表模板

## 一、浮出块（float-out）

目标效果：镜头停在某段时，那段文字**从文档里抬起来**，比原位更大、更亮、有投影，其余部分退到背景。

### 图层（自下而上）

| 层 | 内容 | 关键参数 |
|---|---|---|
| 1 | 页面图（整页，按帧宽铺满） | 300dpi 渲染页图；镜头缩放 1.000→1.035 全程缓推 |
| 2 | 白纸补片：精确盖住目标块原位 | 填充=纸张色（`#fff`），尺寸=裁切框，不能有描边 |
| 3 | 浮出副本：同一裁切区的页图 | **不额外放大**——按正文栏宽裁切（别多带空白栏）+ 8px 内白边，靠补片/投影/压暗产生浮起感；真要放大也只能贴天花板（见下「尺度」） |
| 4 | 投影 + 背景压暗 | 投影柔和（大模糊低透明）；背景 `brightness 45%` + `blur 0.8px`；卡片左右留白 ≥100–120px（实测标准） |

### 运动

- 进：0.5s，smoothstep（`x*x*(3-2x)`），同时完成「抬起位移」＋「背景压暗」（可选极小放大）
- 停：覆盖台词句时长的停留
- 出：0.4s 反向，回落到原位后镜头继续下移

### 尺度检查（先算再渲，别承诺做不到的字号）

两个上限先算清楚再定版面：

1. **整行不折行的字号上限**：`px/pt_max = 画幅宽 ÷ 栏宽pt`，正文最大字号 = `正文pt × px/pt_max`。
   - US Letter 正文栏宽 532pt → 1920/532 = **3.61 px/pt** → 8pt 正文最多 **28.9px**
   - 想要 44px 需要 5.5 px/pt × 532pt = **2926px 宽** > 1920 → 必须拆行重排，那就不是「同一块原文」了，不做
2. **留白**：`单侧留白 = (画幅宽 − 栏宽 × px/pt) ÷ 2`，**再 ÷ 末帧镜头缩放**（缓推 1.035 → ÷1.035）。目标 **≥100–120px/侧**。

实测达标的一组基线（可照抄）：页面基准 **3.15 px/pt** → 栏宽 1676px → 左右各 ~120px 留白、英文正文暗行带高 **25px**、中文对照暗行带高 **34px**，卡片 `x 122→1797`。

反例：把基准推到 3.36 px/pt（正文 26.9px）栏宽就顶死画幅，卡片左右只剩 0–11px、投影全被吃掉——**「贴白带」的根因就在这**。宁可让正文小 7% 也要保住留白。

### 中文对照行（台词中文 / 原文英文时）

- **默认要加**：英文被字号上限压到 ~25px，真正传递信息的其实是中文行；不加等于让观众看「证据纹理」。
- 位置：浮出块底部；字号比英文正文**大一档**（实测暗行带高 34px vs 25px）。
- 强调只用**纯加粗**（术语如「单药」「结直肠癌」「总生存出现数值不平衡」），不加底色块——底色块会被读成一次标记，跟马克笔抢语义。
- 措辞由医学编辑逐字定稿，红线术语照抄，设计侧不润色。
- 浮出块顶部配一行「① 编号 + 中文小标题」（如「② 试验终止 · 继续试验已难改变疗效结论」），右上角挂登记号角标（`BNT122-01 · NCT04486378`）：观众能回查原始出处，也顺手堵住「数据哪来的」这类质疑。

### 笔迹（马克笔高亮）

- 一色一段：核心信息只有两处时用两色（例如黄=「是什么/给谁」、正红=「结局」），不要给每个短语换色。
- 顺序扫：同一段内两处短语先后触发（先因后果），不并发；扫过 ~0.3–0.6s/处。
- 高亮用 CSS transition / 遮罩都行，但**导出时必须禁用 transition、改成时间的纯函数**，否则截帧拍到的全是「半涂 + 压字」的中途态。

## 二、节拍表模板（11s 档，两处浮出）

| 时间 | 画面 | 笔迹/元素 | 对应台词 |
|---|---|---|---|
| 0–1.0s | 页头 + 标题定格（微推近进行中） | — | 报主体名 |
| 1.0–2.6s | 缓下移到 ① 段 | — | 交代背景 |
| 2.6–5.4s | ① 浮出 + 停留 | 黄笔顺序扫过 ① | 「选择了……作为适应症」 |
| 5.4–5.9s | ① 回落，继续下移 | — | 过渡 |
| 5.9–7.4s | 下移到 ② 段 | — | 过渡/技术路径 |
| 7.4–10.2s | ② 浮出 + 停留 | 红笔顺序扫两处 → 印章小落 | 「没能取得好成果」 |
| 10.2–11.0s | 定格收尾 | — | 收尾句 |

要点：
- 每处浮出的**停留秒数 ≥ 对应台词句时长**；对不上调停留、不调台词。
- 全程保持极缓推近（1.000→1.035），否则静止段会产生大量重复帧（帧差校验会直接报出来）。
- 印章落点：**画幅层固定定位**（如 `right:150px; bottom:170px`），不压浮出块正文，也不随卡片缩放位移（放进卡片里会被画幅切掉边）。
- 章内只留一个词：登记号、日期已在卡片角标出现过一次，重复进章会让同一信息出现两遍，且章内小字 <25px 在手机上就是噪点；必须保留小字时给章加 1.5px 白描边或 10% 白底，别让背景正文从小字中间透出来。

## 三、交给实现方时的交付物

1. `_pdf_浮出块_boxes.json`：pt + 目标 dpi 像素两套坐标（裁切框、笔迹范围）
2. `_pdf_浮出块_示意预览.png`：原页 + 描边框 + 图例（标注图）
3. 节拍表（README 里的秒级表）
4. 尺寸账：栏宽/px per pt/正文与中文实高/左右留白（含末帧缩放折算），让实现方有数可对
