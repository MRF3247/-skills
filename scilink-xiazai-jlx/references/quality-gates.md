## 闸门 3：信息守恒

### 做法

1. 从教材提取所有数据型断言（带 % / 千分位数字 / N 篇 / N 倍）
2. 逐条到逐字稿与 PPT OCR 里检索
3. 找不到 → 删掉或改成模糊表述
4. 找到 → 记录源文件位置

### 实际抓出的问题（第二本）

| 教材写法 | 源里实际 | 处理 |
|---|---|---|
| 超过 95% 论文有统计错误 | PPT 写 98.2% | 改 98.2% + 补文献名 |
| 接收率常在 10-20% | 源里没有 | 删数字 |
| 读 100 篇摘要精读 10 篇 | 源里没有 | 删数字 |
| 数据库 60% / 顶刊 30% / 其他 10% | 源里没有 | 改顺序描述 |
| 整体重复率 < 10% | 源里两个口径（20%/15% 与 <10%）| 写清两个口径 |
| 开题间隔 32/20/20/8 个月 | 出自北京大学医学部 | 补出处 |

### 可外部验证的硬数据

文献数字要单独核：查 PubMed 摘要原文，逐项对数值、置信区间、p 值。

案例：UKPDS 34（PMID 9742977）六组数字全部对上，包括 95% CI 与 p 值。

### 结构性事实也要核

- 章号是否连续（1..15 无断号）
- 节号每章内是否从 1 开始连续
- 图号与图片文件是否一一对应
- 交叉引用「第 X 章」是否都存在
- 「十二个字段」vs 表格实际 14 行——这类内部矛盾要扫

## 闸门 4：术语全称

面向零基础读者的教材，**缩略语首次出现必须带中文全称**。目标读者是医学新手，字母串看不懂。

```python
# 把所有英文词抓出来，逐个看有没有全称
import re
from collections import Counter
c = Counter()
for f in Path('.').glob('第*.md'):
    for m in re.finditer(r'[A-Za-z][A-Za-z\s\-]{1,20}', f.read_text(encoding='utf-8')):
        c[m.group().strip()] += 1
for w, n in c.most_common(40):
    print(f'{w:<24} {n}')
```

扫出来分三类处理：

| 类型 | 例子 | 处理 |
|---|---|---|
| 统计缩写 | OR、RR、HR、SMD、MD、CI | 首次出现写「中文名（英文全称）」 |
| 量表/工具缩写 | **HAMD、BDI** | **必补全称**：汉密尔顿抑郁量表、贝克抑郁量表 |
| 中英混排 | **atypical 病例** | **必改中文**：表现不典型的病例 |

规范写法范例（已经对的，不要改）：

```
OR（比值比，odds ratio）
RR（相对危险度，risk ratio）
比例（proportion）
```

中英混杂最刺眼：正文里突然冒一个英文形容词，读者卡住。写的时候就用中文，专业名词靠括号注英文，不要反过来。

## 闸门 5：统计表述验算

教材里的每个换算、每个临界值，都要用脚本跑一遍。凭印象写必错。

### OR 与 RR 不能混

两者只在发生率很低时接近。基线越高，OR 越夸大 RR：

```python
def or_to_rr(odds_ratio, p0):
    odds0 = p0 / (1 - p0)
    p1 = odds0 * odds_ratio / (1 + odds0 * odds_ratio)
    return p1 / p0
```

| 基线 | OR=2 时真实 RR | OR 夸大程度 |
|---|---|---|
| 1% | 1.98 | 1% |
| 10% | 1.82 | 9% |
| 20% | 1.67 | 17% |
| 50% | **1.33** | **33%** |

实测踩过的错：写「对照组 50%、OR=2 对应 RR 大约 1.5」，审方算出来是 1.33，差 11 个百分点。

公式：`RR = OR / (1 - p0 + p0 × OR)`。

### 其它高频硬伤

| 类型 | 容易错的地方 |
|---|---|
| SMD（Cohen 标准） | 0.2 小 / 0.5 中 / 0.8 大，别写成 0.3/0.5/0.7 |
| I 类错误 | α=0.05 即 20 次里错 1 次，不是「5% 的概率结论错」 |
| 置信区间跨无效值 | RR/OR/HR 跨 1，RD 跨 0，就不算显著 |
| 绝对风险 vs 相对风险 | 40%→30% 是相对降 25%，绝对降 10 个百分点 |
| WMD | 就是 MD，加权来自合并过程，不是 WMD 本身带的属性 |
| 主要终点 | ICH E9 允许共同主要终点，但要预先做多重性校正，不能写成「只能有一个」 |

### 研究设计的分组依据不能写反

写流行病学设计时，**每种设计按什么分组**是定义性特征，写反了整段逻辑自相矛盾：

| 设计 | 按什么分组 | 时序 |
|---|---|---|
| 队列研究 | **按暴露**（吸烟组 vs 不吸烟组）| 先暴露，随访看结局 |
| 病例对照 | **按结局**（有病 vs 无病）| 先有结局，回溯查暴露 |
| RCT | **随机**分配 | 先随机，再看结局 |

实测写错的原句：「病例对照的暴露必须发生在**分组之前**」。这句话自相矛盾——病例对照本来就先分组（分病例/对照）、再回溯测暴露。把它当判据，病例对照自己就不符合定义。

正确的红线是**时序**：暴露必须发生在结局之前，不能是「分组之前」。

写完这类段落，逐句问一遍：这个「分组」是按什么的？按错的就是硬伤。

## 反校：页面文字 ↔ 逐字稿

教材写完后，用源素材反过来查教材有没有偏离。两个源都要查，顺序有讲究。

### 双源，且以逐字稿为主

| 源 | 体量 | 特点 |
|---|---|---|
| PPT 帧 OCR | 约 1 万字 | 页面图多字少，术语可能只在讲师口述里 |
| 逐字稿 | 约 7-8 万字 | 覆盖全，但有 ASR 同音错字 |

只对 OCR 会大量误报「无出处」。先查逐字稿，再查 OCR。

### 字面匹配会把「有依据」误判成「无依据」

ASR 会把术语听成同音词，教材写规范名，检索不到：

| 规范术语 | 逐字稿实际写成 |
|---|---|
| PSM（倾向性评分匹配） | 「倾向性 PP 分析」 |
| 置信区间 | 「可信区间」 |
| 效应量 | 「实验效应」 |

查不到时，换同义词、缩写、近音词再查一遍，别直接判「教材编的」。实测 12 个可疑术语里 11 个都有依据。

```python
# 逐字稿拼平，去标点后模糊查
flat = re.sub(r"[\s，。？！、；：]", "", transcript)
for kw in ["PSM", "倾向性", "匹配"]:
    if kw in flat:
        i = flat.find(kw)
        print(f"[{kw}] …{flat[max(0,i-30):i+40]}…")
```

### 真无源的要分类处理

| 类型 | 处理 |
|---|---|
| 数字、研究结论、具体比例 | 删掉或改模糊表述 |
| 教科书级常识（如病例对照的「选择偏倚」） | 可保留，但须在交付说明里主动交代 |

主动交代很重要。不交代，审方会把你的自查结论当新发现重报一遍。

print('页数', doc.page_count)

for pi in range(toc_start, toc_end):
