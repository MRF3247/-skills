# 用论文串讲一个科学进展（诺奖/重大突破）

适用：用户说「我想做一期讲某某奖/某个重大突破的稿，把几篇论文串起来」。
难点不在写，在**选哪几篇、怎么分层、边界写在哪**。

## 一、关键文献从哪来：用颁布方自己的科学背景文档

**不要自己拼「重磅论文清单」当权威源。** 大奖的颁布机构会自己发布科学背景文档，
诺奖的形态（可类推到其他大奖）：

| 文件 | 用途 |
|---|---|
| `press-release` | 授奖词原文、得主生年/单位、份额 |
| `popular-information` | 浅白版科普，**最适合改写文案**；含关键图 |
| `advanced-information` | 科学背景 + **完整参考文献表** + 关键图的出处标注 |

PDF 直链形态：`nobelprize.org/uploads/<年>/<月>/advanced-medicineprize<年>.pdf`。
把 advanced PDF 用 `fitz` dump 成文本后，**参考文献段在文件末尾**——从那里挑里程碑，
并用正文里 `Figure N |` 的图注反查官方认定的关键图出自哪几篇。

**诚实边界（必守）**：官方给的是「关键图出处 + 完整文献表」，**不是一份「官方认定的 N 篇论文」名单**。
自己筛出的 N 篇必须写成「按官方材料梳理的关键节点」，绝不能写「官方认定的 N 篇」。

## 二、叙事骨架：一条暗线 + 四幕

按「这件事做到了什么」分幕，比按年份平铺强得多。通用四幕：

| 幕 | 在干嘛 | 常见形态 |
|---|---|---|
| 一 看见现象 | 有人观察到一个解释不了的现象 | 描述性研究，常在几十年前，样本很小 |
| 二 找到分子 | 把现象落到具体的分子/基因/靶点 | 异源表达、结构解析、功能鉴定 |
| 三 做成工具/方法 | 让领域里其他人能用 | 技术论文 + **命名那篇** + 活体/体内验证 |
| 四 走到人身上 | 临床/应用落地 | 首次人体、首例报告，限定词最多 |

- **指定转轴**：每幕挑 1–2 篇真正的转轴（「这一步之后才有可能」），明确告诉用户哪几篇要讲透。
- **命名那篇值得单列**：一个新名词首次出现的那篇标志方法学定型，是天然叙事节点。
- **落点那篇限定词最多**：首例 / 部分 / 单个患者（n=1），措辞必须回原文（见 SKILL.md「外部 AI 写的稿」条）。
- **一条暗线收尾**：给外行一句能复述的话。写成「X 现象」→「人类拿它做了什么」→「最后回到人身上」。

## 三、双受众分层（不要折中）

同时喂「科研人」和「外行」时，**不要折中成两边都不满足的写法**，而是分层承载：

- **图承载给科研人**：一图 = 一篇论文，首行是硬信息
  （`作者. 期刊 年;卷:页 ｜ DOI ｜ 引用数+来源+快照日期 ｜ 能否免费下载`）。科研人要可核对、可保存。
- **正文承载给外行**：只有一条故事线，**不放数字、不放期刊名、不放引用**。每篇一句白话概括它在干嘛。
- 正文里给每篇留一个「人话」落点（例：第一扇门只让一种小个子过，这扇门什么大个子都放进来）。
- 交付形状：封面大字（≤12 字）+ N 张论文卡 + 1 张时间线总览页；卡与正文的编号要对得上。

## 四、引用数怎么报

- 引用数因来源差异可以很大（同一篇，期刊自报数与 Europe PMC 能差三成以上）。
  **必须标来源 + 快照日期**：`引用 1915（Europe PMC，YYYY-MM-DD 快照）`。
- **早年文献 PubMed 常不收录**（1990 年代初的卷期尤其）：改用 CrossRef 的 `is-referenced-by-count`，
  并在交付里说明换了源，否则用户会追问「PubMed 怎么搜不到」。

## 五、配图版权

- 奖方官网的图通常写明**不得用于商业/营销场景**；出版社论文图是期刊版权，CC BY-**NC** 的 NC 就是非商业。
  带产品推广的账号属营销 → **不要直接搬官方配图**。
- 可行做法：**自己重画示意图**。这类稿里最好画、信息量也最大的两张通常是
  ①「装置/接口示意」（刺激怎么到目标上）②「刺激—响应对应关系」（给什么、出什么）。
- 文字可引用官方新闻稿/科普版的摘录，**按官方要求署名**并在交付里写清要求。

## 六、这类稿的核查清单

1. 官方 advanced PDF 已 dump，参考文献段已逐条看过，里程碑是筛出来的（不是官方名单）。
2. 每篇的 DOI 已核（`api.crossref.org/works/<doi>` 看 title/volume/pages）。
3. 落点那篇的患者基线、n 数、首例口径已回原句核。
4. 每篇标了「能否免费下载」并给了合法路径。
5. 时间量词（毫秒/微秒）与「治愈/部分恢复」类词已回原文核。
6. 引用落位符合平台限制（见 SKILL.md「正文长度与引用落位」）。
