# 医学内容事实核查与素材建档（B站/视频号科普稿）

用户运营医学账号（SciLink B站等），受众=医生/医学生。写稿前必须做事实核查，素材按规范建档。本技能管"怎么核查 + 怎么存档"。

## When to Use
- 医学新闻/试验结果/药物数据要写进科普稿（尤其涉及临床试验、疗效数字、获批/定价传言时）
- 用户要求"查最新资料/论文/新闻""查谁在说/网传出处""保证正确的情报"
- 需要把调研素材整理成编号 md 存进医时知识库素材文件夹（含原文存档目录与 manifest）
- 回答医学数据问题前需要分辨哪些是实锤、哪些是媒体口径、哪些根本没公布

## 铁律（防坑，全部来自真实翻车案例）

1. **每个数字必须挂对试验**。媒体常把早期试验数据挂到最新新闻上（mRNA 案例：全网把 IIb KEYNOTE-942 的 HR 0.51 当 III 期 INTerpath-001 结果传播，连肿瘤专家推文都错）。核查第一问：这数字出自哪个试验编号（NCT/KEYNOTE-XXX）？几期？多少例？**入组数还要看类型**：ClinicalTrials.gov `protocolSection.designModule.enrollmentInfo` 的 `type` 为 `ESTIMATED` 时那是**计划**入组数，不是实际入组数——顶线新闻稿通常不披露 N，媒体与用户就会顺手抄登记页的计划值（实测某 III 期顶线稿全文未给 N，登记页写 900 例/`ESTIMATED`）。`ACTUAL` 才是已发生，稿子里必须写明是哪个。
2. **对照组/试验组方向别写反**（49.1% 是单药对照组，72.4% 才是加疫苗组）。写清数字人群：期别（IIB-IV?）、癌种、是否"切除后辅助/带瘤晚期"。
3. **数据版本随随访时间变**：同一试验 1 年随访 HR 0.443、5 年随访 HR 0.510——引用必须带随访时长。
4. **口径陷阱**：①p 值双侧 vs 单侧不同（Lancet 双侧 p=0.053 vs 幻灯单侧 p=0.0266，同一分析！转述报 HR 最稳）；②"相对风险降 49%"≠绝对差 23 个百分点≠"提升两成"（"提升 X 成"有歧义，写绝对+相对双口径）；③HR≈0.5 白话是"风险几乎减半"；④**相对降幅与绝对率不可互相反推**——新闻稿常只给"相对风险降 X%"（如 42%），没给两组绝对无复发率，不能据此写"复发率从 A% 降到 B%"，也不能把上期试验的绝对率搬来当本期（II 期 4 年 49.1%→72.4% 是 II 期口径，不是 III 期结果）。跨试验比降幅时用绝对率反算相对风险比 (1−试验组率)/(1−对照组率) 再与官方相对降幅并列，两个百分比不要直接相减。
5. **宣传稿数据勿张冠李戴**：医院/公司宣传稿常引用国际数据当自家成果（邵逸夫稿引 Nature 92%/86% 实为 BioNTech 胰腺癌数据）。凡"复发风险降 X%"先问：这是谁的试验的数据？
6. **数字出处要核全官方载体**（2026-09-07 翻车教训）：同一研究三个官方载体报**不同数据**——官方新闻稿只报 HR（风险比），会议摘要（ASCO 等）报 headline landmark 率，期刊正文 Results 段才报全。曾把 ASCO 摘要官方 5 年率 68.8% 误判成"讹传"（只核了全文+新闻稿、漏核会议摘要）。判断"官方数字 vs 讹传"前：新闻稿/会议摘要/论文正文**三个载体都找齐**再下结论。详表见 `references/clinical-data-verification.md`。
7. **试验终止 ≠ 方案/适应症失败**（用户 2026-09-07 两次纠正）：原因未披露的终止（INTerpath-007 皮肤鳞癌 46 人停）不能当"适应症选错"证据；公司破产（Gritstone）≠ 疗效失败。引用失败案例按证据分层：结果读出+归因清楚 > 终止但原因未披露（只能说"停了"）> 资金/战略原因；并区分试验终止/战略放弃/监管拒绝（如 2024 加速批准被 FDA 挡回）/资金断裂四类。
8. **缩写首次出现必须注全称+一句大白话**（用户 9/3、9/7 两次强调，连 CRC 都漏过）：面向医护受众的中文稿同样要注（CRC=结直肠癌、TMB=肿瘤突变负荷、MSS=微卫星稳定型、RFS/DMFS/OS、HR、CI、DSMB、ctDNA…）。
9. **引用链接必须与论断逐句相符**（2026-09-07 用户亲自点开验证、两次抓包）：给"出处链接"前在页面里搜论断关键词确认真存在——曾引 CRI 年度报告撑"黑色素瘤 TMB 最高"，用户指出该页根本没有相关段落（真出处=Frontiers 综述/Alexandrov 2013 Nature）。判财经数字"失真/夸张"前先做量级验算再定性：曾把"空头单日亏 50 亿美元"凭感觉判为失真——实际 5280 万股空头 × 每股涨约 $111 ≈ $58 亿，量级吻合（媒体口径 $4.8-5B）；市值变动≈流通股×股价变动，空头单日亏损≈空头股数×每股涨幅。
10. **同一指标在两套定义下打架时并列口径，禁止相加、禁止只取其一**。疫情类计数最典型：州按「相关死亡」（症状出现且检测阳性后 30 天内死亡即计入）自报一个数，CDC 按「死于该病」只认另一个数，两者可差两三倍，且 CDC 会说明正与州流行病学家委员会统一死亡定义。写成「过去两年共 N 例死亡」＝跨口径相加，联邦不认；正确写法是「A 方报 X 例、B 方认 Y 例，定义尚未统一」。确诊数/住院数/归因类计数同理。
11. **累计型数字（「今年全国 X 例」「累计 X 例」）必须回官方数据页取当日值**。用户递来的稿子里这类数字常是几天前的快照（实测同一指标 10/1 为 3,887、10/8 已 4,080，稿子写的还是前者）。修正旧值并标快照日期，原句的来源链接只作溯源保留。顺手取走官网数据页上的分层旁证（辖区数、暴发数、接种状态分层）——它们常比总数更适合上屏，也常是稿子漏掉的强素材。
12. **绝对表述与程度词一律回原文原句核**（论文稿/奖项稿必查）：凡「首个/首例/首度/首次」「全盲/失明/复明/治愈/完全恢复」「唯一/突破」这类词，去原文 abstract 或官方进阶材料里找那句话，用**原句自带的限定语**改写。AI 代笔（Kimi 等）与媒体最爱在这类词上升级，而专业读者第一批就挑这些。实测同一条诺奖稿里三处：①「部分恢复」被写成「全球首例光遗传学人体治疗」（原文 "first reported case of partial functional recovery"，此前已有光遗传人体试验但未报疗效）；②原文 "visual acuity limited to light perception" 被写成「全盲」（患者尚存光感）；③原文 "a latency of only microseconds" 被写成「约半毫秒」（差约一个数量级）。**同一段里被吞掉的限定词也归此类**：体外/体内、培养/活体、单例(n=1)/队列、动物/人体、部分/完全——核 AI 代笔稿时就按这张表逐项搜。
13. **量级数字挂不上出处就删数字换机制描述**。稿子里「至少几十毫秒」「大约 X 倍」这类数字若找不到可核来源，不要留一个「大致对」的数——改成机制描述（实测改法：把「视觉发生要至少几十毫秒」换成「光要先激活视紫红质，再经转导蛋白、磷酸二酯酶等多步酶促放大，速度远达不到微秒量级」）。有机制的描述不需要引用就站得住，未经核实的数字则是硬伤。
14. **出处时效：默认只用「当年」发布的资料**（用户明确要求，并因此推翻过一整版已成型的对照报告）。判据是**资料发布日期**，不是数据所属年份：2026 年发布的《2025 年统计公报》算当年资料；2018 年白皮书、2022 年论文、2013 年联合调查一律不算。做法：①每个论断先搜当年版本（政策文件、年度公报、当年调研报告往往已覆盖旧结论）；②当年确无同口径数据时，明确写「查不到 + 原因」（如某调查已停更于 X 年），把旧资料降级为背景或不引用，**不要拿旧数当现状**；③交付时显式声明「已剔除的旧资料」，否则用户会以为你没查过；④跨国/跨机构对比类选题，两方证据必须落在**同一年份**，不同年份的数字不许并排进同一张对比表。

## 跟进型任务：新数据 vs 用户已有稿件

用户会甩来一条新新闻并说「看看我当时写的稿子，有什么更新的」。这是**增量对比**，不是重新概述新闻（新闻讲什么一句话带过即可）。

1. **先定位旧稿**，顺序：本地内容库（素材库 / 资讯内容 / Obsidian）→ 用户自己的飞书 wiki。用户口中的「新闻稿」常是视频口播稿，正文往往只在飞书 wiki：`lark-cli docs +fetch --doc '<https://my.feishu.cn/wiki/…>' --as user --doc-format markdown`（域是 `docs` 不是 `doc`，参数是 `--doc` 不是 `--url`；正文取 `data.document.content`，编辑批注在 `reference_map`，批注常含用户当初要求的口径修正，值得一并读）。找不到就直接要链接，不要凭标题猜旧稿内容。
2. **先从旧稿里抽「悬空点」**：哪些是当时未公布、只在等某个会议、或只是企业/媒体口径的。新数据的全部价值就是填这些洞——把旧稿原话与新值一一对应地列出来。
3. **输出四块，顺序固定**：①悬空点揭晓（旧稿说法 → 新数据，表格）②旧稿完全没有的新信息 ③旧稿仍然站得住的部分（防止用户误以为要整篇推翻）④新数据也不能说的坑（缺哪个绝对值、哪两个口径不能混）。
4. **股价/市场反应单独一栏**：数据新闻几乎都带股价，但涨跌是**预期差**不是疗效判据——达预期却暴跌是 sell-the-news（预期先被炒满），不能读成"数据不行"；反向也一样。
5. **旧稿被推翻就直接说**，不要写成"部分需要微调"来保面子。

## 证据分级（回答"能保证正确的情报"时的分层）
官方新闻稿/论文/ClinicalTrials 登记 > 专业行业媒体（OncoDaily/Fierce/Endpoints）> 一般媒体转载 > 公司/医院宣传稿 > 社区/传闻。
回答"哪些能保证正确"：只列一手源能撑住的；把"未公布/推测/媒体口径"单列一栏；每条标快照时间。**信息没有 = 本身也是情报**（"III 期具体数字一个字没公布"经常是重要结论）。

## 付费墙新闻：找免费权威替代源

用户会直接问「这篇要注册才能看，帮我找个报同一件事、不用注册、且比较权威的信源」。这是**换源不是降级**——免费源常比付费稿更全。阶梯（自上而下取第一个可读的）：

| 档 | 源 | 特点 |
|---|---|---|
| ① | 监管机构一手公告（`fda.gov/drugs/resources-information-approved-drugs/...`） | 永久免费无登录，是付费稿的原始出处，含适应症/剂量/主要终点原值 |
| ② | 学会官方媒体（ASCO Post 等） | 免费，口径与监管一致 |
| ③ | 专科行业媒体（OncLive / Targeted Oncology / CURE 系） | 免费，**实测数据比付费稿更全**：同一条 FDA 批准新闻，付费稿只写 DFS，专科稿另给 5 年 OS、HR 与完整不良反应表 |
| ④ | 一般媒体（Reuters / ABC / CBS） | 补事件现场计数与各方说法 |

验证「是否真要注册」：`curl -sL -A "<桌面 UA>" <URL>` 后 grep `register to (read|continue|view)|sign in to (read|continue)|subscriber-only|create a free account`，无命中即可视为公开发布。**官方站（fda.gov）对 curl 返回 404 属反爬而非死链，用浏览器复核一次再下结论**，别据此换掉更权威的源。

回报形状：按权威度排序，每条附一句话简介 + 一句「比原稿多了什么」，并主动点出免费源多出来的数据（总生存、不良反应、总生存未获益这类）——那些往往正是原稿为省篇幅砍掉的，也是用户写稿时最需要的。

## 政策/监管类新闻：正文读不到时的三角还原

上面那套阶梯是为「临床/获批」新闻设计的。**政策与监管类**（投资审查、出口管制、法案提案、监管新规）换一套：这类稿子的价值不在数据细节，而在「文件状态 + 被管范围 + 明确豁免」，而这三样恰好都能从一手源拿到，不必死磕付费稿。

1. **先分诊，再选路**：`curl -sL -A "<桌面 UA>" <URL>` 后数正文段落（`grep -c '<p'`，再抽几段看长度）。段落数为 0 或只剩「注册/登录/订阅/摘要」= **服务端截断型登录墙**，归档与浏览器同样是这堵墙，别在 Wayback/Jina 上耗；有正文只是被遮 = 渲染/反爬，才走 `blocked-page-recovery` 的梯子。
2. **不假装读过原文**：交付第一句明说「正文在登录墙后，以下由同日一手源交叉还原」，并交代实际拿到的范围（标题/副标题/摘要）。用户会核。
3. **源分工**：机构一手新闻稿（含部长/主管原话）= 文件状态与官方范围；通讯社（Reuters/AP）= 数字、金额门槛、豁免项、截止日期最准；政策向媒体（Politico 等）= 常是唯一逐条列出「被管对象」的来源；律所 client alert = 条文级解读与实务影响（多半还给出底层法律的时间线）；中文转载只用来看舆论，口径常被简化或加戏。
4. **文件状态行必须单列**（提案 / 征求意见稿 NPRM / 最终规则 / 生效日 / 意见截止日）。政策新闻最大的翻车是把「提案」写成「已生效」。政府站的 program 页面常滞后于新闻稿，Federal Register 搜不到该文件 ≠ 没发布——以新闻稿为准，并注明「FR 尚未刊出」。
   **反向也翻：外媒的 `draft` 不能当中国文件的性质。** 实测一份国内已正式发布的文件（标题带《…（试行）》、正文写「**现发布**……请各培养单位制定实施细则、加快推进实施」、落款盖公章带文号），被外媒写成 `released draft policy documents`，中文稿照抄就成了「一组专家起草的征求意见稿公开」——发布级硬错。判据只看中文原件的**发文动词**：「现发布／现印发／请遵照执行」＝已发布（试行也是已发布）；「现征求……意见」「请于 X 日前反馈」才是征求意见稿；只出现在新闻稿里、无发文机关与文号的，才叫「提案/传闻」。内外媒用词冲突时**以中文原件为准**，并在稿中改成准确表述（可补一句「目前处于试行阶段，各校细则陆续出台」把不确定性写清楚）。
   附带的检索纪律：这类文件**实质在附件**（正文只有发布与实施要求），核事实和上图都要打开附件；附件之间还常有口径差异（同一份文件里博士版给两种实践成果形式、硕士版给三种），那往往才是可写的点。
5. **两家权威源口径冲突时并列，不裁决**（如一家写「禁止」、一家写「须通报」）：两方原话都摆出来 + 标「待原文确认」，不从中挑一个写成事实。
6. **命中范围与豁免必须成对交付**：只写「禁止了什么」是半条新闻。必须同时给出「明确不管什么」（哪类交易被排除在外），否则读者会得出与事实相反的结论。
7. **金额口径不可相加**（承接铁律10）：同一条赛道的交易额常有三套——法案/媒体引用的年度总额、数据库的潜力值（含未到账里程碑）、监管口径的首付额；逐条标来源，不合并、不算增速。

完整源层级表、文件状态判定与交付模板见 `references/policy-news-triangulation.md`。

## 引用论文：先判「能不能下载」再选文献

用户写医学稿时会直接要求「不能写成新闻或科普建议，要引用具体论文，最好高 IF，要能下载」。选文献的顺序：**结论对口 → 可免费下载 → IF 档位**，后两项不可颠倒——拿不到全文的顶刊不如拿得到的 PMC 稿。

判定链（全程免 key，按顺序做）：

1. **OpenAlex 一次问清 OA 状态与所有全文位置**：`api.openalex.org/works/doi:<DOI>` 看 `open_access.oa_status`（gold/hybrid/green/diamond=能免费拿，closed=付费）、`best_oa_location`、以及 `locations[]`——**预印本免费版常落在 acceptedVersion 里**（出版商版付费的 PNAS / Vaccine 文章，就是靠 `locations` 里的 medRxiv 链接拿到可下载 PDF）。
2. **Europe PMC 的两个字段都要看**：`isOpenAccess=N` ≠ 付费。`inPMC=Y` 即 PMC 免费作者稿（NIH 资助的 Science 论文属这类）；反向也成立——EID 等 diamond OA 期刊在 EPMC 会误报 `Subscription required`，一律回原刊域名复核再定性。
3. **curl 403 / reCAPTCHA 一律不当作付费墙**：PMC 文章页与 PDF 用 curl 会返回约 1.8 KB 的 “Checking your browser” reCAPTCHA 页；thelancet.com / pnas.org / medrxiv.org 对 curl 返回 403（Cloudflare 反爬）。这些都不是付费证据，付费与否用 OpenAlex 的 oa_status 判。
4. **PDF 直链形态**（实测可下）：PMC `https://pmc.ncbi.nlm.nih.gov/articles/<PMCID>/pdf/<file>.pdf`，`<file>` 从文章页 HTML grep `href="[^"]*\.pdf` 取出，不要猜文件名；medRxiv 只有 `https://www.medrxiv.org/content/medrxiv/early/YYYY/MM/DD/<doi>.full.pdf` 这种 early 形态直连返回 `200 application/pdf`，`/content/<doi>v1.full.pdf` 会 403 或跳 `/node/`；EID 主文 PDF 无稳定直链，给免费 HTML 正文页即可。
5. **确认真的打开**：`browser_navigate` 到 PDF 后用 `browser_vision` 问「标题/作者是谁、有无付费或登录提示」——这是唯一可靠的成功判据；`browser_console` 里跑 async `fetch` 评估可能直接 500，别依赖它。
6. **下到了 PDF 也要先验证它是不是「DRM 空壳」**：部分出版社档与作者自存档是 Adobe Content Server 保护的 PDF（原件里带 `CSML:PProt` 标记）。这种文件文件名正常、体积正常（实测 6 页 638 KB）、HTTP 200 + `content-type: application/pdf`，但**文本抽取返回 0 字符、逐页渲染全白**，肉眼和浏览器里都打不开。判定三步：① PyMuPDF 逐页 `get_text()`，长度全 0 → ② `get_pixmap()` 存图看是否全白（4 张图、内容流只有十几字节是典型征状）→ ③ 在原件里搜到 `CSML:PProt` 即确认。这类文件直接删掉换途径，别反复重下——**「能下载」不等于「能用」**，抽得出文字或用视觉核过内容才算到手。推荐语里也别把这种档当「作者自存免费版」写出去。

交付形状：**按结论分组**，每条 = 论文题名 + 期刊（IF≈档位）+ 能否下载 + 直链 + 一句话怎么用；下不到的单独一栏并附免费替代（预印本 / PMC 作者稿 / 免费行业报道），**不要静默换成低档信源**。IF 一律写「≈」并注明以最新 JCR 为准（用户会去核）。命令配方见 `references/open-access-paper-sourcing.md`。

## 素材建档规范（用户素材库 医时知识库/.../1.mRNA科普素材/ 等）
- 编号 md：`NN-短名（YYYY-MM-DD核实）.md`；frontmatter：title/type/created/source/note。
- 正文结构：状态速览 → 数据表 → 【写稿必看】数字纠偏（流传错误数字+正确口径）→ 证据分级清单 → 来源清单（**原链接+渠道+日期**，逐条）。

- 付费墙判定（2026-09-07 纠偏）：Europe PMC 返回非 OA **≠ 期刊官网付费**——ascopubs.org 等官网常标 "Free access"（限免开放），浏览器直接可读全文；curl 403 多为反爬非付费墙，先开 browser/快照页验证再标 partial（实例：JCO-26-00835 曾因 Europe PMC 非 OA + curl 403 被误标"付费墙"，实际官网免费）。Europe PMC API `search?query=DOI:"..."&format=json&resultType=core` 查 isOpenAccess/inPMC；有 PMCID 走 PMC 镜像。
