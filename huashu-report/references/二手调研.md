# 二手调研（desk research）：证据分级、量化基线与不披露的处理

适用：竞品 / 促销 / 行业调研——不访谈、拿不到内部数据，只能靠公开材料。目标是让「资料汇编」升级为「有口径、有证据强度、有边界」的调研报告。

## 三条铁律

1. **先分级，再下结论。** 证据强度排序：官方活动页 / 规则页 > 第三方交易或支付数据 > 厂商战报通稿 > 聚合清单与行业博客 > 从业者社区发言。摘要里每条结论后面挂一个「证据：xx（强/中/中强/弱）」，读者才知道哪句能引用、哪句只能当线索。
2. **打不开的源不许留。** 一条事实如果源页取不到正文（只有搜索摘要、域名打不开、页面只剩导航），**删掉这条事实**，或在正文标注「仅标题级 / 媒体级信息」并在「局限」里点名。宁缺一条，不留一条无法核实的断言——用户会点开链接核对，错一条整篇掉信用。
3. **不披露本身就是发现。** 厂商普遍只公布「折扣力度」不公布「成交」时，别写成空缺，写成一句结论：「这条赛道的数据生态是力度透明、成效不透明」。同理，找不到案例的品类（如高客单长决策链的 SaaS 在购物节几乎无公开案例）要把**负结果**写进发现段，不要因为「没查到」而静默略过。

## 清单类数据的量化基线（比举例子强一个量级）

行业博客常发「N 个促销/deal 汇总清单」。不要只从中挑两个例子，而是**把它变成分布**：

1. 抓下整页 → 按条目切块（编号行、`deal` 段落为界）→ 正则抽折扣百分比。
2. 脚本算：有明确数值的条目数 / 总条目数（**这就是分母**）、中位数、均值、分箱（≥60% / 50-59% / 40-49% / 30-39% / 20-29% / <20%）。
3. 正文写「49/68 条给出明确折扣，中位数 40%、均值 41.3%，50% 及以上占 43%」——这一句比十个「某家打了 X 折」有说服力，且可复算。
4. 顺带统计**形式**分布：首年折扣 / 送月份 / 加赠额度 / 免费迁移 / 终身买断。形式的分布往往比幅度更能说明商业模式。

## 成效：三个必须自己先拆掉的替代解释

- **季节性 ≠ 促销有效。** 旺季峰值可能来自预算周期（年底必须花完的钱）。写成效时把「行业总盘季节性」（第三方支付/交易数据最可靠）和「某家活动做得好」分开，后者没数据就不写。
- **低基数高增速。** 「伙伴增长 100%」在小基数上很容易，不能线性外推成趋势。
- **客户战绩 ≠ 自身收入。** 服务商爱报「我的客户在大促里卖了多少」——那是寄生叙事，标明它是「客户战绩」而不是产品收入。

## 中介数据源优先级

要「成效」硬证据时，优先找**支付 / 结算 / 平台方**这类第三方数据（它们有动机也不得不披露聚合口径），而不是媒体转述。找不到就退到「官方规则页 + 厂商战报」，并在方法页把「自述、无审计」写明。

## 抓不到正文时的取文姿势

抽取工具返回 blocked / 空 body 时，别在同一路径上重试：`curl -sL -m 30 -A "<桌面 UA>" <url>` 落盘 → 正则剥 `<script|style|noscript|svg>` 与标签 → `html.unescape` → 去空行。批量时写成一个 `fetch.py`（url 字典 + 逐条落 `.txt`），后面所有引用都从落盘文本里核对原句，重抓只影响一个文件。

## 可复用的交付骨架

摘要 N 条（每条带证据强度）→ 研究问题 / 样本与口径 / 证据强度表 → 按问题组织的发现（每节先给一句结论，再给表格与参数）→ 反例与替代解释 → 风险与反方观点 → 有边界的建议（标明是推断层）→ 局限 → 案例索引（每条带链接）→ 来源清单。

要点：**建议必须回链发现**，且单独标「推断层」；案例索引每行带可点击出处，读者能逐条点开核。正文里不要写「我是怎么抓到这些页面的」。
