# B站脚本大纲模板（产品演示/干货向，官方号）

产品演示向/干货拆解类视频的标准大纲结构（2026-08 为 SciLink 系列A 打磨成型，实测直接可用）。每个选题产出时按此结构写，再批量同步到飞书（总览文档+子文档，见 feishu-cli-workflows skill 的「总文档 + N 子文档批量创建」）。

## 固定章节（缺一不可）

1. **一句话定位** — 这期做什么、用什么建立印象（例：用真实录屏演示 X 从输入到产出的全程，用"快"建立第一印象）
2. **目标受众** — 按受众锚定写，不写"大众"（例：临床医生（核心，统计基础弱）+ 医学生）
3. **视频信息** — 主标题 + 2 个备选标题 / 时长 / 内容形态（实操录屏/口播/对比/图文快闪）
4. **开场钩子（0-15s）** — 画面 + 口播逐字；四种钩子类型：录屏冲击 / 痛点提问 / 左右对比猜谜 / 反直觉数字
5. **主体结构** — 分镜表格，三列：`时间 | 画面 | 口播/字幕要点`，每行一个镜头段
6. **产品植入点** — 列出本集植入哪些卖点，软植入优先（演示为主，卖点藏在功能里）
7. **结尾 CTA** — 关注引导 + 评论区互动引导，与评论区钩子呼应
8. **合规提示** — 分级 🟢🟡🔴 + 逐条写死"禁说/只能说"（见下方合规红线）
9. **评论区钩子** — 一个具体问题，用于互动 + 反哺下期选题
10. **封面建议** — 画面 + 大字文案；对比类直接把对比图做封面（视觉冲击最强）

## 分镜表格写法

```markdown
| 时间 | 画面 | 口播/字幕要点 |
|---|---|---|
| 0:00-0:20 | 录屏：输入关键词→生成中 | 钩子：30秒出选题 |
| 0:20-1:10 | 展示报告第一屏 | 一个完整选题 = 选题方向+研究类型+关键词+样本量，逐项指读 |
```

原则：时间连续覆盖全片、画面写具体（哪段录屏/什么对比图）、口播列写"信息点"不写逐字稿。

## 官方号产品宣传合规红线（B站实测）

- **代写代发类服务绝不上公开平台**：论文协助/基金指导等高价服务（报价、周期、案例）只在私域聊，B站提一个字都可能被认定代写代发 → 封号风险
- **效果承诺全部软化**：内部话术"帮你把1-3分论文提升到5分以上"→ 公开版"提升论文质量""冲击更高分区**的可能性**"；"IF>3"只能作为功能输入参数演示，不是效果承诺
- **演示数据指标必须标注口径**：模型准确率 0.875/97% 等必须注明"演示数据集结果"，不代表用户数据效果
- **对比类内容只比客观属性**：图表对比只比美观度/清晰度/信息量，不比"论文分数"；已发表论文来源期刊打码/淡化（避免贬低原作者联想）
- **不点名贬低竞品**：内部话术"市面竞品全是黑盒"→ 公开版"市面上很多工具训练过程不可见，看不到过程"
- **医疗内容边界**：科研工具讲"写论文/做统计"不涉及诊疗建议，相对安全；演示用疾病案例只讲科研场景，不延伸治疗建议
- **绝对化用语禁用**：最/第一/100%/包发/保证 等词不进标题和口播

## 发布节奏建议表

按「目的」排列（建立认知→视觉信任→痛点共鸣→收藏干货→差异化→场景解法→高价值收尾），避免连发两个同形态演示；每期留评论区钩子，评论反哺后续选题。
