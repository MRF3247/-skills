# SciLink 平台投放合规（小红书聚光为主，其它广告平台同理）

## 何时读
- 用户要投小红书 / 聚光 / 千川等商业化平台，或在写投放素材、落地页、私信与客服话术
- 用户丢来某平台的广告规则文档问「我们会不会踩、多严重」
- 审对外文案时的第 5 桶（平台投放合规）

## 结论先行：最致命的一条
小红书《商业化风险积分管理规则》4.1 P1「教育培训高危禁投」原文禁止推广
**论文、期刊、课题的代写代发与辅导**。

SciLink 现行官网定位是「从科研想法到论文投稿，一套 AI 完成临床科研全流程」，功能含
「投稿准备 / Cover Letter / 审稿回复信 / 科研论文草案」——审核会把这类表述整体归入论文服务，判 P1。

P1 = 9 分 = **素材下线 + 账号冻结 30 天**。一次命中就跨到冻结档，没有缓冲。
**这不是措辞问题，是行业准入问题：没有任何一个类目能干净地装下「帮医生做科研发论文」这个业务。**

## 判级机制（解释为什么是 9 分而不是 3 分）
1. 机器扫词，命中关键词即进高危池送人工；
2. 人工判业务属性——只问「这条广告最终卖什么结果」，不问你是工具还是服务；
3. 判级按行政/法律风险：论文代写代发属国家整治的学术不端领域，与「非法服务」同档 P1；普通学科教育才落 P2。

## 风险矩阵（按严重度，审素材时逐条过）

| 严重度 | 命中条款 | 会踩在哪 | 后果 |
|---|---|---|---|
| 🔴 必炸 | 4.1 P1 教育培训高危禁投（论文/期刊/课题代写代发与辅导） | 「从想法到**论文投稿**全流程」「投稿准备、Cover Letter、审稿回复、论文草案」 | 素材下线 + 冻结 30 天 |
| 🔴 必炸 | 同上条款中的「**课题**」 | 写标书 / 基金申报 / 课题设计辅导 | 同上 |
| 🟠 高 | 4.2 P1 低备高推（低风险资质推高风险业务） | 用「软件/信息技术服务」类目推广科研教育服务（好比便利店执照开药店） | 9 分 + 冻结 30 天 |
| 🟠 高 | 4.2 P1 撞审（反复提交违规素材） | 被拒后改几个字重提同一套「论文」话术 | 从拒审升级为扣分 |
| 🟠 高 | 教培行业投放规范 | 三甲医生背书、顶刊同款、专家站台——明确禁「利用科研单位/学术机构/专业人士/受益者名义作推荐证明」 | 拒审；重复转撞审 |
| 🟡 中 | 4.1 P2 限制的教育业务 | 科研辅导落教培灰区 | 3 分 + 拒审 |
| 🟡 中 | 4.1 P2 限制的医疗业务（含基因检测） | 素材出现「基因检测 / 基因表达 / 生信分析」 | 3 分 + 拒审 |
| 🟡 中 | 4.1 P2 不正当广告营销 | 点名 SPSS、GraphPad 或同类 AI 做对比拉踩 | 3 分 + 下线 |
| 🟡 中 | 保证性承诺（教培准入硬规） | 「一键见刊」「保录用」「一区」「三个月出文章」 | 拒审，累犯计 P2 |
| 🟢 低 | 3.2 行为规范 | 见下节「覆盖范围」 | 与上述条款合并计分 |

## 覆盖范围：不止投放素材
规则 3.2 明确「推广内容」涵盖：投放素材、组件、落地页、**落地页二跳**、私域沟通场景、**私信**、
客服咨询、对话框、头像、评论、app、小程序。

**销售私信一句「帮你发核心期刊」= 同一条违规。** 内容团队改素材、销售不改话术，等于白改——审这类问题时必须把私信/客服话术一并列入清单。

## 禁词表（投放素材 / 落地页 / 私信 / 客服一律适用）
论文｜SCI｜核心期刊｜一区二区｜投稿｜见刊｜录用｜接收｜返修｜审稿｜Cover Letter｜润色｜查重降重｜辅导｜代写｜代发｜包发｜课题｜标书｜基金申报｜出文章｜发文章

## 可改写方向（卖点落回工具与数据）

| 原表述（高危） | 改写 |
|---|---|
| 从科研想法到论文投稿，一套 AI 完成全流程 | 临床数据从清洗到出图，一套流程跑完 |
| 一键生成符合期刊要求的论文草案 | 自动输出标准三线表与出版级矢量图，直接贴进你的稿子 |
| 推荐候选期刊并生成 Cover Letter | 该功能在小红书渠道不上素材（移到 B 站 / 私域） |
| 帮你搞定从选题到发表的每一步 | 把统计和画图交给工具，把判断留给你 |
| 三个月帮你出一篇能投的文章 | 删除：保证性 + 效果承诺双重违规 |

能讲的卖点：数据清洗、变量角色识别、统计分析、KM/ROC/森林图/DCA/三线表、建模与评估、数据脱敏与沙箱、可追溯不编造。

## 类目两难（回答「换个类目能不能绕」）
教育培训 → P1 直接禁投；医疗健康 → 需资质且限具体医疗项目、限制基因检测；软件/IT 服务 → 能开户，但推广科研服务可能判低备高推。
**结论：只能把小红书上推广的「产品定义」整体改成数据统计工具，不能靠换类目绕。**

## 处置与缓冲条款
P0 15 分 / P1 9 分 / P2 3 分；R≥3 预警、≥6 冻结 14 天、≥9 冻结 30 天、≥12 冻结 45 天、≥15 永久。
自然年清零但已执行的处罚不撤销；5.4 条：主动承认并上报、经核实未造成实际损害可**降一级**处置；申诉窗口 14 个自然日。

## 渠道分工（给用户的建议口径）
小红书只讲工具能力；B 站 / 视频号口径宽松，可讲「从选题到投稿」。同一套脚本不能跨平台直接搬。
