# SciLink 产品能力全景（11 大类）

> 来源：用户提供的产品能力清单（2026-11-03 录入）。
> ⚠️ 口径说明：本清单覆盖面远大于官网帮助文档 20 篇（帮助文档几乎只有数据与建模）。按 SKILL.md「能力边界判定」规则，本清单条目属**「产品/PM 功能清单」层（意向）**，涉及具体功能可写「支持/即将支持」，但对外做投放承诺前须与帮助文档或产品侧核对；与帮助文档说法冲突时并列提出，不自行裁决。

## 一、文献与信息检索
- 查文献：同一题目中英文各查一遍，覆盖国际期刊和中文期刊，每条给标题、年份、期刊、DOI（引用核验用的身份证号）、摘要要点
- 按条件筛：近半年/一年/三年、指定年份、影响因子或分区、只要核心期刊
- 引文追溯：谁引用了它、它引用了谁、相似文章（看方向来龙去脉、找奠基性研究）
- 取全文：开放获取论文可取正文，用于精读方法学、核对具体数据
- 核验引用真伪：给 DOI 或标题，查是否存在、作者期刊年份是否对得上
- 批量排参考文献：Vancouver/APA/MLA/BibTeX/RIS
- 搜网页：最新指南、政策法规、期刊政策等实时信息（带来源与查询时间，不当文献证据用）

## 二、选题与研究设计（动手前阶段）
- 研究方案完整性体检：研究对象、干预/暴露、对照、结局是否说清，缺哪块
- 想法转可落地问题：对象、比较、结局、随访时长，再给候选题目
- 研究空白评估：只在真检索到证据后判断，查不到就说查不到
- 研究设计包：研究类型、纳排、分组、随访、统计方法、样本量、可行性；随机化方案（简单/区组/分层区组/聚类）
- 假说生成：临床观察转可检验假说，含竞争解释与证伪方式
- 伦理与注册判定：是否需伦理审查、能否知情同意豁免、是否需注册、材料准备（只判定与起草；批准号/注册号必须为真）

## 三、数据处理（脏表→可分析表）
- 上传文件合规校验（格式、大小、可读性、编码）
- 提取表头、每列类型与缺失率
- Excel/TSV → 标准 CSV；多工作表自动纵向合并（合并范围由用户定）
- 按缺失率剔除变量列 / 剔除缺失过多的行
- 去重：按患者编号等唯一标识判重，避免误删「协变量凑巧相同」的不同病人
- 异常值：识别（IQR / Z 值）+ 处理（中位数/均数/众数替换、整行删除、仅标记）
- 缺失值填补：中位数/均数/众数/删除/多重插补
- 假缺失识别：「0 表示没做」「－ 表示未测」声明为缺失，防假 0 混入均值
- 有依据的单元格更正：仅当能由同行其它列反推真值才改，留审计清单（改哪格、旧值新值、依据）
- 非数值列编码：独热/标签/目标/数值解析
- 派生新列：单位换算、比值指数（如 TyG）、取对数、按阈值打标
- 按条件筛行：亚组、按阈值纳入排除
- 改列名：英文变量名、清理脏列名
- 按指标阈值二分人群（高/低两组，用于生存分析等）
- 建实验数据集 + 探索性分析（EDA）：变量分布、组间差异、数据质量问题，出 HTML 报告

## 四、统计分析（真实数据上算，出统计量与 P 值）
- 两组：t 检验（自动判方差齐性选 Student/Welch）、秩和、配对 t
- 多组：方差分析、Kruskal-Wallis，整体显著后 Tukey 事后两两比较
- 分类变量：卡方、Fisher 精确（小样本）、分组交叉表（率、构成比）
- 相关：Pearson / Spearman
- 正态性检验（决定参数/非参数）
- 基线特征表（表1）：逐变量总体与各组描述 + 组间 P 值，连续变量按正态性自动选均数±SD 或中位数（IQR）
- 频次分布：阳性率、各取值例数、缺失数
- 趋势检验：随分组等级单调升/降（不只是「有差异」）
- 回归：多重线性、Lasso（变量多时自动筛）、Poisson/负二项（事件次数）、有序 Logistic（轻中重等级）、限制性立方样条（U/J 型剂量反应）
- 生存分析：KM + log-rank、Cox 多因素完整报告（生存曲线、HR 森林图、ROC、校准曲线、DCA、PH 检验、列线图）
- 竞争风险：有竞争事件时算累积发生率（不能用 1−KM，会高估）
- 重复测量/纵向：混合效应模型（同一病人多次测量，普通回归会算错）
- 倾向性得分匹配（PSM）：基线不可比时配对，报匹配前后平衡性
- 模型增量价值：NRI / IDI（仅报 AUC 提升期刊不太认）
- 判别力比较：DeLong 检验（AUC 差 + P 值），可指定部分 AUC（高特异度区间）
- Bootstrap 置信区间（小样本、事件少时正态近似区间偏窄）
- 多重共线性 VIF（回归前必查）
- 多重比较校正：Holm/Bonferroni/FDR 等
- 聚类：无结局标签时分组（探索性，明确声明「不等于真存在几个亚型」）
- 样本量：两组均数、两组比例、生存分析、诊断准确性四种设计，失访率自动上浮
- Meta 分析：多研究效应量合并（随机效应 + 异质性 + 森林图）
- 跨库变量可比性核查：多库联合（如 CHARLS+HRS）前确认同一变量是否同物
- 一致性分析：双人筛选 kappa、观察一致率（系统综述须披露）

## 五、机器学习建模
- 单算法训练：12 种分类算法，清洗/转换/特征筛选/数据划分/超参全可配
- 多算法比较：同台对比，出主报告 + 每算法子报告
- 自动调参（AutoML）
- 训练前参数推导：按样本量、正类比例、缺失率推荐算法与超参
- 不平衡处理：类权重、SMOTE 过采样
- 模型对比：两模型在同一测试集比 AUC（配对 DeLong）
- 训练取证：真正入模特征列、实际生效超参（提交配置可能不一致）、任意阈值下的灵敏度/特异度/PPV/NPV

## 六、图表与可视化
- 统计图：柱状/条形/折线/饼/散点（可带回归线与 95% 置信带）
- 多面板拼版：a/b/c 分图，按期刊规格排版
- 投稿级矢量件：PDF/SVG/EPS，按刊物稿约设栏宽、字号、线宽、色板（不止 PNG）
- 改图样式：配色、标题轴名（可把图内文字翻英文）、图例名称位置、刻度字号——只改呈现不改数据
- 三线表转图片：插进 Word/WPS 不变形
- 流程图/方法框架图：可编辑 drawio 源文件 + 矢量 SVG（研究设计图、纳排流程图、技术路线）
- 甘特图：阶段起止、入组排期
- 看图和自检：读图的真实内容（轴、趋势、标注），不是生成完就看不到

## 七、论文写作与稿件处理
- 各章节写作/润色：标题、摘要、引言、方法、结果、讨论、结论；中英双语，按国际期刊或中文核心写法
- 结构检查：STROBE（观察性）/TRIPOD（预测模型）/CONSORT（随机对照）报告规范核对
- 论文主线与证据链梳理：每个结论对应哪个结果/图/表/引用；主线不清时反向重构段落
- 数据与代码可用性声明：核对共享状态、访问限制、仓库版本，写可追溯声明
- 投稿前自检：以审稿人眼光自查（结论有证据撑吗、统计能复现吗、规范齐吗）
- 模拟同行评审：三名互不相见「审稿人」各出一份报告再综合（不预测录用结果）
- 论文精读卡：拆解问题、方法、公式、图表、证据边界，带原文定位

## 八、参考文献与投稿（稿件外的事）
- 参考文献核验：去重、查真伪、补 DOI/PMID、正文引用与文献列表对齐、按格式排序
- 期刊匹配：按稿件内容推荐目标期刊，准备投稿材料
- 按刊排版：栏宽、字号、行号、表格版式（柳叶刀/JAMA/中华医学会系列等有明文规格的可套）
- Cover Letter 起草
- 审稿回复：拆解意见、绑定修改位置与证据、逐条写回复信
- 出版校对：清样 vs 终稿比对、核数字术语图表编号、回 Author Queries（作者/单位/基金/结论等敏感信息只标出不擅改）

## 九、学术产出物（不只是论文）
- 汇报幻灯片：真实可编辑 PPTX（组会、文献汇报、答辩、会议演讲，带来源与讲稿备注）
- 会议海报：A0/A1/A2 实物尺寸，HTML 可直接打印或单页 PPTX
- 专著/教材章节：按主编体例（章节边界、图表编号溯源、术语统一、引用格式一致）
- 医学科普：公众号/患者教育/科普讲稿（管能不能这么说、不承诺疗效、每个数字有出处）
- 行政公文：请示、报告、汇报材料、按领导意见逐条修改
- 科研基金/开题报告：按目标—方法—预算—里程碑组织
- 技术交底：论文转技术问题 + 方案 + 实施例草稿

## 十、文件与文档操作
- 读文件：PDF、Word、Excel、CSV、TXT、Markdown、SVG/流程图文字
- 导出：Word（中文投稿稿/英文投稿稿/内部报告/Nature 版式四套模板）、HTML、PDF、Markdown、Excel（仅表格）
- 直接改已有 Word：插图（按正文首次引用位置自动定位）、追加章节或表格、查找替换、统一格式（A4/页边距/页码/三线表/字体）、删某一节
- 结构化配置落盘成 JSON（预处理方案、执行日志）
- 文档结构解析：先看清标题树与每节段落数、表格数，再动手改

## 十一、两个别的
- 中药靶点查询：方剂/单味药/单体成分的潜在靶点（BATMAN-TCM 2.0，区分「数据库已有证据」与「模型预测」）
- 长期记忆：记住专业背景、科室、在做的课题、格式与表达偏好，跨会话不用重复交代
