# SciLink 对外文案审查判定表

审查对象：用户丢来的宣传稿 / 软文 / 口播稿，要求「根据刀客轻研的能力看有没有问题」。

## 0. 先做三步取证，再下判断

1. 读本地三源：`产品资料/SciLink_平台科研能力清单.docx`（最新、最全，含技能层＋工具层）、`SciLink帮助文档.md`（20 篇，只覆盖数据与建模）、`会议纪要/`（口径原话）。
2. 抓官网首页 `https://www.drscilink.com` + 该篇官方新闻稿。软文 90% 的越界句是从官网抄的，不查就会把「官网口径」错判成「文案编造」。
3. 定位每句宣称属于哪一层：帮助文档实锤 ／ 能力清单（工具与技能层）／ 官网+新闻稿（对外口径）／ 全无出处。无出处的是编造，必须删。

## 1. 四桶分类（每条文案都要落桶，四桶全给）

| 桶 | 判什么 | 后果 |
|---|---|---|
| 专业硬伤 | 术语越界、方法学不成立、边界被抹掉 | 医生/审稿人当场质疑，人设崩塌 |
| 事实与资质 | 证书、备案、成立时间、安全承诺 | 虚假宣传风险，三甲合规核查会要编号 |
| 广告法与平台规则 | 比较广告、极限词、未标广告、承诺性表述 | 限流、投诉、处罚 |
| 公司合规红线 | 保证性承诺、代写一条龙（会议7） | 内部违规 |

## 2. 高频越界句 → 降级写法

| 越界写法 | 为什么不行 | 改成 |
|---|---|---|
| 支持「因果分析」 | 无 IPTW/DID/工具变量/中介；清单原文「不把探索性相关解释为因果」「横断面相关不作因果推断」；PSM 只是混杂控制 | 「生存分析与混杂控制（PSM 倾向性得分匹配、限制性立方样条等），按观察性研究解读，不作因果定论」 |
| 选题助手「估算样本量」 | 样本量是独立工具，需效应量/事件率/脱落率输入；边界写明「不编造样本量、效应量、事件率」 | 「参数化样本量测算（需填入效应量与事件率假设，由你确认）」 |
| 「一眼生成符合期刊要求的高清矢量图」 | 稿约逐刊不同（栏宽/字号/色板/行号），无平台能保证「符合」 | 「按目标期刊稿约设置栏宽、字号、配色，支持 PDF/SVG 导出（以当前版本为准）」 |
| 「从选题到投稿产出可直接使用的交付物」 | 选题/写作/投稿在帮助文档 20 篇零收录，属新版技能包与官网口径；写作有反 AI 痕迹环节 | 「产出可交付的草稿与全套材料，最终版本由研究者把关」 |
| 「上传整理好的数据就能出报告」 | 存在硬限制（见 §3），不披露就是体验落差 | 补一句数据规格说明 |
| 「一键横向对比多种算法」 | 展示模型数受套餐限制 | 「按套餐展示 6/12 个模型，可一键同台对比」 |
| 「完全替代统计老师 / 不用学统计」 | 产品自己讲「可交统计老师交叉验证」；且宣称替代专业判断越界 | 「把关和跑数交给你+平台，结论判断仍在你」 |
| 点名竞品「无法完成 X」 | 通用大模型写代码可做统计，断言可被反证；属比较广告，需客观依据 | 「通用模型强在知识问答，交付物需自己串工具；平台把环节串成一条线」 |
| 「最致命 / 最容易被忽略 / 实打实」 | 极限词＋自我夸奖 | 「常被忽略 / 容易被低估」 |
| 「实打实能支撑三甲医院合规核查」 | 对医院做承诺，核查不过即虚假宣传 | 删；只列证书与编号，让读者自己判断 |

## 3. 必须在文案里披露的产品硬限制

- 分组变量只允许一列；每个分组标签 ≥50 条；二分类只能 2 类。
- 不支持非数值与时间格式（会被置空，需先转换）。
- 训练固定用「分组变量」作标签列；两分类须显式指定 positive_value。
- AutoML 展示模型数按套餐（如 596→6 个 / 1096→12 个）。
- 文献检索不等于可复现检索策略：不能写「可作论文方法学的正式检索策略」。

## 4. 资质与事实核对清单（发布前必须拿到）

1. ISO 9001 证书（编号 + 认证范围是否覆盖科研软件）
2. ISO/IEC 27001 证书（编号）——「信息安全管理体系认证」这种模糊写法必须落成标准编号
3. 等保三级备案证明（编号）
4. 互联网药品信息服务资格证书（编号；该证管「药品信息服务」，**不可当科研数据合规背书**）
5. 隐私政策 / 用户协议条款页：数据留存时长、是否用于模型训练、数据所有权归属
6. PDF/SVG 矢量导出实机验证（配一张真实 ROC 或森林图截图）
7. 工商登记信息（成立日期、公司全称）——新闻稿口径不算证

安全口径冲突要先统一：「不存储数据、删任务即彻底删除」（会议8 原话）vs「临时缓存 24 小时物理擦除」（官网文案）——两套说法同时对外，被追问会露怯；以隐私政策落地条款为准。

## 5. 稿件形态自检

- 第三方测评口吻 + 只推一家 = 商业广告：按广告法须显著标「广告」，否则被举报/限流。最稳是改由官方号发布。
- 缺少免责/边界句：补「以产品当前版本为准」「不承诺录用与发表」「研究者署名与判断自负」。
- 全篇只夸不断言边界，反而降低可信度：主动写出「做不到什么」的段落，医生更信。
