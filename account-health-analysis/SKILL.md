# 对标账号健康度与流量归因分析

判断对标账号"现在还能不能模仿"、诊断流量下滑原因。已验证：15 个 B站 科研账号健康度 + 解螺旋流量下滑归因（2026-08）。

## 健康度 = 趋势 × 质量 × 活跃度

| 维度 | 算法 | 判定 |
|---|---|---|
| 趋势 | 近12月播放中位 ÷ 前12月播放中位 | >1 上升 / 0.5-1 平稳 / <0.5 衰退 |
| 质量 | 平均赞播比 | ≥4% 优 / 2-4% 良 / <2% 差 |
| 活跃 | 近12月发稿数 | ≥12 活跃 / 6-11 低活跃 / <6 濒停 |

评级：健康上升 / 健康平稳 / 亚健康 / 衰退/停更。
注意：**衰退/停更 ≠ 内容没人看**——可能是停更（大喵 2026 中位 411 但只发 5 篇）。评级卡必须带原始数据让用户自己解读。

## 核心陷阱：累计播放积累效应

B站稿件播放是**累计值**（2021 稿 8 万 = 攒 5 年；2026 新稿 8 千 = 发几天）。直接按时间画原始播放 → 横轴越靠右天然越低 → 误判"账号在衰落"。
**解法：月度聚合中位数**（每月发稿的播放中位数连线），或散点图不做连线。

## 关键信号

- **播放/粉丝比 <1%** = 账号被判限流（只剩死忠粉丝在看，无自然推荐）——"广告号"信号
- **发稿量暴增年份** = 批量搬运直播回放/灌水起点（解螺旋 2023 月均 14→205 篇，播放中位同步腰斩）
- **赞播比持续走低** = 内容吸引力下降（信息密度低）
- **月度中位逐年表**（2018-2026 每年中位/月均发稿/赞播比）一眼看出拐点年份

## 流量下滑归因方法（双重验证）

1. **本地数据**：月度中位趋势 + 发稿量 + 赞播比的拐点（哪一年开始跌、当时发生了什么）
2. **主页线索**（数据不足时去 space.bilibili.com/{uid}/video）：最新 30-40 条投稿的类型/时长/标题模式/播放量——判断"内容形态"是否变质
3. **归因框架**（解螺旋案例）：内容形态崩塌（原创长教程 → 直播回放灌水 → 30-60 秒产品广告短视频）+ 硬广限流（标题塞满产品词）+ 质量断崖 + 赛道周期
4. **对比法**：同赛道"内容导向"账号（中立实测/争议话题，如顺利毕叶 AI 检测 40-100 万）vs "广告导向"账号（自家产品广告，如解螺旋 100-400 播放）——流量天壤之别

## 结论句式

"不是流量下滑，是账号变质"——从内容号变广告号（2023 直播回放灌水 → 2026 纯产品广告短视频），自然流量枯竭只剩粉丝基本盘。对官方号的启示：产品内容 ≤5% 且要有独立价值，纯广告 = 限流死刑。
