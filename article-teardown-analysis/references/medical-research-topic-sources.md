# 医学科研类「人物 + 事件」选题信源地图

受众锚定：要发论文的医学生、靠论文评职称的医生、刚入行的科研人。选题能不能用，先看这一点。

## 四类信源

| 类别 | 常去信源 | 搜什么 |
|---|---|---|
| 奖项与人物 | 诺奖官网（含 interview / advanced info PDF）、Lasker、Japan Prize、各学会奖、高校获奖通稿 | 谁得了什么奖、获奖当天的细节、前哨奖拿过哪些 |
| 政策与监管 | 国家卫健委（科研诚信通报、专项治理方案）、人社部与各省人社厅（职称申报通知）、教育部 | 论文工厂通报、职称改革口径、AI 代写规定 |
| 学术圈争议 | 科学网（人物 / 讣闻 / 观点）、中国科学报、科技日报「创新谈」、人民日报评论、Nature daily briefing、Retraction Watch、BioArt | 拒稿、抢发、撤稿、顶刊争议、诺奖漏人 |
| 商业与转化 | 公司 IR 页 `news-releases`、ClinicalTrials.gov、BioSpace / Endpoints / Fierce、行业券商口径 | II/III 期顶线、主要终点是否达标、股价反应 |

## 检索配方

- 组合式：`年份 + 主题词`（如「2026 撤稿 论文工厂」「2026 职称 论文 改革」「2026 拒稿 人物」），中文一轮、英文一轮。
- 先官网后媒体：政策回 .gov.cn 原文，奖项回颁奖机构官网，试验回 IR 页 + 注册库；媒体只用来取时间线与解读。
- 人物题顺手查「诺奖/大奖漏了谁」——学界长期争论的落选者往往是比获奖通稿更有信息量的角度（但要引学界观点，不要自己下「不公」的判决）。
- 存量人物（多年前的故事）也能做：TED 演讲页 + 自传 + 维基三件套即可成稿，且无时效压力。

## 排序维度

| 维度 | 判断 |
|---|---|
| 受众匹配 | 是否直接关系到「发论文 / 评职称 / 投稿被拒」 |
| 时效窗口 | 热点 2-4 周内做；政策类常青；纪念类要快 |
| 素材可得性 | 有一级源（官网/论文/通稿）才列，只有二手汇总的降级 |
| 事实风险 | 政策各省口径不同；在研试验只能写已公布的终点 |

## 坑

- 政策类**不能给统一结论**：同一个改革，各省通知的适用范围差很多（例如某类人员「不作硬性要求」不等于全国取消论文）。落稿要写「某省口径 + 出处日期」。
- 高校 AI 使用新规这类话题，网上多为二手汇总，正式使用前必须回查教育部与校方文件原文。
- 讣闻/纪念稿：生平以医院或单位讣告为准，克制、不煽情、不推断死因。
- 已发表数据一律标快照日期；播放量、死因排名这类数字现查现写。
