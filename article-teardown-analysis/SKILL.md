# 爆款文章逆向拆解

## When to Use

用户（B站/视频号/小红书医学科研内容运营）丢来一条公众号/自媒体链接并问：
- 「这种文章是怎么写的」——要写法模板，不是读后感
- 「它是从哪找到的信息」——要源头溯源
- 「怎么引流到自己产品的」——要转化漏斗拆解
- 「是热点稿还是把旧事拿出来写」——要时效定性

不适用：单篇医学事实核查（走 `med-content-factchecking`）；从新闻回溯原论文（走 `primary-paper-backtracking`）。

用户（B站/视频号/小红书医学科研内容运营）常丢一条公众号链接问「这种文章是怎么写的」「它是从哪找到的信息」「怎么引流到自己产品的」「是热点吗」。

**核心认知：这类稿子绝大多数没有独家信息。** 它们是「英文一级源编译 + 中文重写 + 升华 + 文末转化组件」。先按这个假设去验证，比逐段赏析快得多，也更接近作者的真实工作方式。

## 四问工作流（按顺序做）

### ① 稿源溯源：信息从哪来

先抓一手页面（公众号走 `china-source-fetch` 的 curl+UA 配方，同时拿到 `nick_name` 与发布时间），再列分层来源表：

| 层级 | 典型来源 | 用途 |
|---|---|---|
| 一级 | TED 演讲页（带逐字稿/字幕）、当事人自传、本人官网、原始论文 | 80% 的细节与时间线 |
| 二级 | 维基百科、时代百大/诺奖官网等权威榜单 | 生平时间线、奖项、学历 |
| 三级 | 中文二手转述（同行已写过 N 遍） | 句式、过渡、升华段落 |
| 配图 | TED.com 截图、医院/学会示意图、门户图库、出版社书封 | 全是搜来的，不是自制 |

- 一级源里找「能落到身体感受」的细节（她原文的症状描写、比喻），那是全文抓力所在。
- 英文人物类，TED 页 + 维基 + 自传三件套基本能覆盖全文；先查这三处，再看中文二手。
- 结论直接写：「全文没有一处独家信息，来自 X 与 Y」。

### ② 写法模板：拆成段落功能表

逐段标功能，不写读后感。典型骨架（多篇爆款共用）：

1. **秒级时间戳冷开场 + 一个具体身体/感官感受**（"某年某月某日清晨7点"）
2. **提前给结局**（她后来出了书、上了TED）——让读者知道有好报才往下读
3. **前史动机**（为什么她会走进这个领域）
4. **亲历过程**（第一人称转述，全文最有抓力）
5. **专业定性 + 流行病学数据**（权威感）
6. **康复/反转**（亲情、努力、时间跨度）
7. **升华到人生哲学**（给转发理由，不是给阅读理由）
8. **实用清单（口诀/自查表）+ 软广**（给收藏理由与变现出口）

判断依据：**文章结构往往就是它抄的那场演讲的叙事顺序**。查一级源的讲述顺序，再对照稿子，能一眼看出哪些是原创、哪些是照搬。

### ③ 引流拆解：怎么把人导到产品

读文末转化组件，逐句标作用（痛句→产品名+促销符号→服务流程图→情绪句→行动指令→免费诱饵→次级关注→分隔留白）。三个通用机制：

- **微承诺（micro-commitment）**：第一步只要求极小动作（"报一下你的科室"），不要求留手机号/付定金。人开口说过一句，后面被推销的抗拒就降一档。
- **免费诱饵必须靠人工交付**："免费领取初步选题计划"听着是资料，实际是定制方案，**必须聊过才给得出来**——等于把免费领取偷换成免费咨询，比送 PDF 高明。
- **宽进窄出**：正文完全离题（中风故事 vs 论文辅导）才能破圈拿泛流量，末尾窄广告把泛流量筛成目标客户。**正文 100% 纯净是为了保住转发，曝光量是用"没广告"换来的**；顺序永远是升华在前、广告在后。

⚠️ **实锤与推断必须分开写**：页面上能看到的（句子、结构、分隔条）是实锤；加企微后的私域路径（拉群/直播/训练营/报价）没进去过就是推断，要标注「行业通例，未核实」，不能当事实讲。用户会去核实。

### ④ 存量稿 vs 热点稿判定（三步，30秒）

1. 找文中**最新一件事**的日期，与今天比：差 1 年内算热点，5 年以上基本是存量
2. 找有没有**明确触发事件**：新论文/新指南/新政策/纪念日/当事人新动向
3. 反查一级源发布日期：一级源本身就老，稿子必然是重写

- 反向证据最有力：**当事人近期有曝光而稿子没挂**，说明作者是从素材库挑人，不是看到新闻才动笔。
- 存量稿叫常青稿（evergreen），商业价值在：可排期、素材免费已验真、数据可预测、零采访零版权、长尾搜索带量、可换角度复用。代价是没有当日爆发。一年发几百篇的号，主力必然是存量稿。

### ⑤ 接一步：同类题材怎么挖

拆完必给「可挖的同类题材」清单，不是列感想。做法：

1. **先定受众**：这批题给谁看（要发论文的医学生 / 靠论文评职称的医生 / 刚入行的科研人）。匹配不上受众的题，再热也不列。
2. **按四类信源并行搜**：奖项与人物 / 政策与监管 / 学术圈争议 / 商业转化。每类用「年份 + 主题词」组合，中英各搜一轮。信源清单见 `references/medical-research-topic-sources.md`。
3. **每题只写四行**：时间、一句话事件、为什么戳受众、建议角度 + 素材链接（附一句话简介）。写不满四行说明素材不够，别凑数。
4. **两个维度排序**：受众匹配度 × 时效窗口。最后给一张「最推荐立刻做的 3 个 + 理由」表。

## 纪律与坑

- **指控稿子写错之前，必须先核一级源。** 维基/官网/演讲原文对不上的才算错；只凭印象质疑"学历/机构名写错了"极易翻车（很多看着像笔误的，其实是对的）。先用 `Special:Export/<条目>` 抓维基 wikitext 核字段，再下结论。
- 数字类（播放量、排名、死因位次）最容易过期：一律现查官网实时值并写快照时间，旧口径（如"第三大死因"）标注年代而非直接判错。
- 医学人物稿的常见科学软肋：把已被学界削弱的框架（如左右脑二分，学界称"左右脑神话"）当成结论升华。拆解时要单独点出来——用户要把这套结构搬到自己号上，得知道哪段不能抄。
- **「转化成功」类故事必须核到底层结果**：个人官网与公司 IR 稿爱写「多个 II 期阳性、都进 III 期」，而实际常有主要终点未达标、靠预设亚组才改善、或对照药数据更好。写进稿子前查试验终点、行业媒体（BioSpace/Endpoints 一类）与股价反应——把 mixed 讲成 success 是这个题材最容易翻的车。
- 人物深挖时，一级源**不止本人官网**：官网是宣传口径，学术事实回官网与论文，转化事实回试验注册与行业媒体，家事/学历等个人细节回机构通稿（不同媒体口径会打架，取机构口径）。

## 输出规范（用户偏好）

- **结论先行**，第一句就给"是/不是"的定性，再给证据。
- 用表格压缩对照（时间线、漏斗、段落功能），清单逐条列全不省略。
- 术语首次出现配一句大白话 + 生活比喻。
- 外部链接每条附一句话简介（原话：总不能让我一个个点进去看吧）。
- 数据标快照日期。
- 拆完别停在分析：**主动接一步**——按用户受众（要发论文的医学生 / 靠论文评职称的医生）给"可挖的同类题材"清单，按匹配度+时效窗口排序，并说明最推荐立刻做的前 3 个及理由（做法见 ⑤）。
- **选题清单要落成飞书文档**（用户的「内容选题库」）：每题配一个 checkbox「选这条」方便他勾，末尾给优先级表。写入配方与 XML 骨架见 `references/feishu-topic-library.md`。
