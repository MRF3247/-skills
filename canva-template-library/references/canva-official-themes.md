# Canva 官方主题分类（小红书帖子模板）

## URL 规律

```
https://www.canva.cn/templates/?category=tAEUgd5tLWo&fTheme=THEME_XXX
```

- `category=tAEUgd5tLWo` = 小红书帖子模板分类（用户原始链接 `adj=eyJFIj...` 是它的 base64 编码）
- 每页 50 个，翻页加 `&continuation=50/100/...`
- 从列表页 script 提取全部 fTheme 值：`document.querySelectorAll('script')` 文本匹配 `THEME_[A-Z_]+`

## 关键事实

**热门模板常无主题标签**：从全量列表（posts/）抓的前 150 个热门模板，翻主题分类页 10 页（500 个）仍匹配不到约 2/3。原因：Canva 主题筛选基于模板元数据标签，热门模板未必打标。
