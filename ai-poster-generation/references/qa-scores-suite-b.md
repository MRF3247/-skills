## 批量生成脚本教训（这次踩的坑）

- bash 脚本里用双引号包提示词（提示词内含 `"STEP 01"` 等半角引号）→ 引号提前闭合、整行被拆成命令执行（`command not found` / `No such file or directory`）
- 修复：改用 **Python subprocess 传参**（list 参数，无引号问题），一次跑通
- 批量中断会残留半成品节点（url 数为 0）→ 重跑前 `libtv node delete <名>` 清理，否则 create 报同名已存在
