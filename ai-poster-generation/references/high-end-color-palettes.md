# 高级配色方案补充（2026-08-07 实测）

## 清新蓝主色方案（用户指定「清新蓝主色 + 装饰色自定」时首选）

- **主色**：雾霾蓝（介于天蓝与灰蓝之间的柔和蓝，如 #7FB5D6 系）——清爽不廉价，比纯天蓝高级
- **装饰色**：珊瑚橙（蓝色的互补色，占画面 5%-10%，只用于小面积细节：手柄/箭头尖/靶心）——互补撞色形成视觉焦点
- **基底**：米白纸底（学术感 + 留白区干净）
- **辅助**：深蓝灰（线条框架/图形轮廓，理性克制）
- **原理**：蓝橙互补撞色 = 焦点 + 活力；米白压底 = 高级不腻；三色克制符合「配色克制」共识

- 卡2：顶部留白 9 / 配色 8.5 / 元素 9 / 无文字 10 = 9/10

## 配套 prompt 写法

```
【配色】米白色纸张底，清新的雾霾蓝色（介于天蓝与灰蓝之间的柔和蓝）为主色调，
少量珊瑚橙作为点缀装饰色（只用于<具体小元素>等小面积细节，占画面5%-10%），
深蓝灰用于线条框架与图形轮廓。整体蓝白清新、克制高级。
```

注意：颜色全部用自然语言描述（雾霾蓝/珊瑚橙/米白），不写色号（#HEX 会被引擎渲染成乱码文字）。
