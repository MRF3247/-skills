# 抖音对标账号调研（找同类博主 + 主页链接）

用户做多平台内容运营（抖音/小红书/视频号矩阵），会定期找对标博主。典型场景：已知几个订阅博主（如 dontbesilent 聊赚钱、戴小胖、李守洲），要发现更多同类。

## 前置认知：抖音反爬边界（别浪费时间）

- **抖音搜索页和搜索 API 不可直接爬**：页面 JS 渲染，搜索结果需签名参数（X-Bogus），curl 拿到的 HTML 无任何用户/标题数据。不要尝试 curl 搜索页。
- **视频页/用户页标题也抓不到**：抖音页面标题由 JS 动态加载，og:title 缺失（实测 2026-08）。B站/知乎/公众号是 SSR，可抓。
- **可行路径**：用 `web_search` 搜「博主名 + douyin.com/user」或「博主名 + v.douyin.com」，从搜索引擎索引里提取抖音官方主页链接。

## 标准流程

1. **画像归类**：先归纳用户已有对标博主的类型（商业思维/赚钱认知、电商培训、线下课、知识付费等），据此定搜索关键词
2. **多轮并行搜索**：每轮 3-4 个候选博主名 + 主页格式关键词（douyin.com/user、v.douyin.com）
3. **提取链接**：从搜索结果标题「XXX的主页」+ URL 提取：
   - 有效格式：`https://www.douyin.com/user/MS4wLjABAAAA...` 或 `https://m.douyin.com/share/user/MS4wLjABAAAA...`
   - 搜索描述里的「抖音号是xxx」「已有N个粉丝」可用于交叉确认身份（注意：索引缓存的数据可能过时/失真，粉丝数以抖音内为准）
4. **去重与甄别**：同名博主多、矩阵号多（如张琦有多个号、参哥矩阵十几个号），按「抖音号 + 简介 + 定位」挑主号
5. **交付**：完整列出账号名 + 主页直链；查不到的明确标注原因（如"未找到直链，抖音内搜索可进"），不硬凑；标注快照时间

## 已知坑（实测 2026-08-05）

- **搜索引擎包装链接不可用**：搜到的 `/goto?url=CAES...` 是搜索引擎内部跳转，不能给用户。只给 douyin.com/user/ 或 m.douyin.com/share/user/ 直链。
- **验证码中间页**：部分 douyin.com/user/... 链接落地是「验证码中间页」（标题含"验证码中间页"）——该链接当前不可直访，标注让用户在抖音内搜索。
- **v.douyin.com 短链**：短链可点但无法预知落地用户，尽量给长链 sec_uid 格式。
- **商业/知识付费博主有争议风险**：如参哥（海参哥）曾被抖音「厚黑学/伪成功学」专项治理、评价两极。交付时标注风险（"可看流量打法，别学话术"），让用户自己判断。
- 链接来自搜索引擎索引，**未逐一验证可用性**：交付时如实说明，用户点开确认。

## 与得到大脑（Get 笔记）联动

用户会把抖音对标博主订阅进得到大脑知识库（新媒体运营库已订阅 4 个：戴小胖/1348333、dontbesilent 聊赚钱/1348332、dontbesilent聊赚钱/1348330、李守洲/1334057，全 douyin）。找新博主后可：
- 在 App 内订阅后，用 getnote-api 的 `knowledge/bloggers` 读取、`blogger/contents` 拉 AI 总结 + 原文逐字稿做对标拆解（先订阅后由得到大脑自动同步视频，无需自己下载）

## 用户偏好

- 清单完整列出（账号名 + 主页链接），查不到明确标注原因，不硬凑
- 数据标注快照时间
- 对标交付应区分「流量打法可借鉴」与「内容价值可学习」，争议博主如实提示
