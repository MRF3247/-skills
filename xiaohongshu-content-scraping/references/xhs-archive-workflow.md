## 博主主页解析（curl + JSON）

```python
import re, json

html = open('/tmp/xhs_profile.html', encoding='utf-8', errors='ignore').read()

# 1. userPageData（博主信息）
idx = html.find('"userPageData"')
start = html.find('{', idx)
data, _ = json.JSONDecoder().raw_decode(html[start:])
bi = data['basicInfo']          # nickname / redId / desc / ipLocation
for it in data['interactions']: # follows / fans / interaction 的 count
    print(it['name'], it['count'])
for t in data.get('tags', []):  # 认证标签（浙江大学等）
    print(t['name'], t['tagType'])

# 2. notes 双层数组（笔记列表）
idx = html.find('"notes":')
arr, _ = json.JSONDecoder().raw_decode(html[html.find('[', idx):])
notes = []
for inner in arr:               # [[{noteCard},...], ...]
    for card in inner if isinstance(inner, list) else [inner]:
        nc = card.get('noteCard', {}) if isinstance(card, dict) else {}
        if nc:
            notes.append((nc.get('displayTitle'), nc.get('interactInfo', {}).get('likedCount')))
```

要点：
- `notes` 是双层数组，内层元素是 `{"noteCard": {...}, "xsecToken": "..."}`；noteCard 里有 `displayTitle` / `interactInfo.likedCount`（字符串）/ `xsecToken`（后续爬详情用）
- 主页 HTML 只渲染首屏笔记（约 10-12 条），**不要翻页**（分页 API 需签名）——首屏列表足够做选题洞察
- 标题若出现 mojibake（`Codexç´è¿Deepseek`）：`s.encode('latin-1').decode('utf-8')` 修复

## 博主档案.md 模板

frontmatter（title=博主名·博主档案 / 博主 / 主页 / 小红书号 / 标签 / 数据快照 / 粉丝 / 获赞与收藏）+ 章节：
- `## 👤 博主信息`：身份/简介/粉丝/定位/跟踪价值（⭐ 数 + 一句话）
- `## 📋 笔记列表（快照日期，按赞数排序）`：表格 标题|赞数|类型
- `## 💡 选题洞察`：**爆款规律**（列出高赞选题 + 公式）/ **数据差的选题**（规律）/ **核心洞察**（反常点，如「爆款 1.6 万赞但粉丝 10+ = 有流量无粉丝」）/ **对本账号的借鉴**
- `## 🔄 后续跟踪计划`：低频率逐篇爬高赞笔记 / 下次发主页时刷新列表

## 数据差笔记诊断（第 8 步细节）

判断基线（2026-08-07 定）：收藏/赞 < 0.5；发布 > 30 天赞 < 200；评论/赞异常。
好数据参考线（同日两条 4800+ 赞实证样本：酸奶糖yogurt🍬）：收藏/赞 ≥ 1.2 且分享/赞 ≥ 0.15 = 强收藏+强转发干货；分享/赞 > 0.1 说明读者愿意转给同门/同事（比单纯收藏高一级）。
素材文档加 `## 📉 数据诊断（避坑分析）` 表格：问题点 | 具体表现 | 避坑经验。
诊断 5 维：①标题是否埋搜索词 ②封面 1 秒价值信号 ③教学化 vs 记录化 ④正文普适钩子 ⑤账号垂直度。
沉淀进 `内容增长/小红书避坑经验.md`：条目 = `### #N 一句话经验（来源博主·主题）` + 现象 → 根因 → 行动准则 → 来源链接。

## 已验证选题/数据规律（2026-08-07，12+ 篇实测样本）

- **信息差工具清单 = 收藏率之王**：「发了4篇SCI后明显感觉到信息差的恐怖😱」850赞/1673藏，收藏/赞 1.97——「身份背书 + 情绪词 + 分类工具清单（文献/AI写作/检索/图表）」结构可复制
- **提问帖/讨论帖 = 评论率之王**：「如果我用Ai写综述能发几区？？？」151赞/137评（评论/赞 0.91）——开放式学术焦虑问题让评论区自己吵；此类数据评价标「讨论帖」而非数据差
- **经典方法论 + AI时代对比 = 爆款公式**：酸奶糖yogurt🍬 两条连爆（4839/7057/951 与 4946/6161/838）——「XX年前的经典 + 吊打AI + 反问/焦虑标题」+ 原文献截图当配图（低成本）
- **表情包/梗图 = 分享驱动**：1210赞/1207分享/156藏——分享≈赞、收藏率 0.13；用途是拉活跃不是沉淀
- **文献拆解类内容**（momo8866）：火=「能量产」式可迁移套路+吐槽顶刊+提问互动+吃瓜串讲；扑=纯术语裸奔（Tfr/Tfh）+技术陈述+系列编号文——钩子层（情绪/悬念/互动）决定生死，专业深度只是背景板
- **「信息差」叙事比「避雷」叙事更能驱动收藏**：市司（1.97）vs 栗子学姐（1.14）
