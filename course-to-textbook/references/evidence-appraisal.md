# 证据等级与质量评价：写教材“判断篇”时的选型与口径

课程类素材几乎不教“怎么判断一篇文献靠不靠得住”。补这一篇时，框架选择、术语口径、链接都要给准，否则零基础读者会学成一套半懂的评语。

## 一、按研究类型选工具（最实用的一张表）

| 要评价的是 | 工具 | 出处 / 判定要点 |
|---|---|---|
| 随机对照试验 RCT | **RoB 2**（Cochrane 偏倚风险工具第 2 版） | riskofbias.info；Cochrane 官方推荐，取代 2008/2011 的旧版 |
| 非随机干预研究 | **ROBINS-I** | 同一体系 |
| 队列研究、病例对照研究 | **NOS**（Newcastle-Ottawa Scale） | 观察性研究的通用评分 |
| 系统评价 / Meta 分析 | **AMSTAR 2**（16 条目） | 2017 年 BMJ；评的是**综述本身做得规不规范** |
| 通用、想快速过一遍 | **CASP 清单** | casp-uk.net/casp-tools-checklists，免费，按研究类型分 9 种 |
| 多种研究类型（另一套） | **JBI 清单** | 澳大利亚 JBI |

**三个必须讲清的区别**（讲混了读者会用错工具）：

1. **AMSTAR 2 不评价综述里纳入了哪些研究**。综述本身的质量 → AMSTAR 2；里面单项研究的质量 → RoB 2 / NOS。
2. **STROBE / PRISMA / CONSORT 是报告规范，不是质量评价工具**。它们只管“作者有没有写清”，不管“做得对不对”。一篇符合 STROBE 的文章可能方法上漏洞百出。
3. **CASP 最适合零基础**：它不是打分表而是一组问题，答完就知道大不太对。

## 二、RoB 2 的五个域

1. 随机化过程（分组是否真随机、分配方案有没有藏好）
2. 偏离既定干预（分组后有没有换组、有没有人知道自己在哪组）
3. 缺失结局数据（退出多少、缺失是否与结果相关）
4. 结局测量的偏倚（评结果的人知不知道分组）
5. 选择性报告结果（有没有只报想报的指标）

每个域给三个判断之一：**低风险 / 有一些顾虑 / 高风险**。

教材里不要教读者去填那张 Excel 表，改成“拿这五个问题对着方法部分问一遍，有两个答不上来可信度就要打折”。

## 三、不用工具也能问的三问（时间不够时的最低档）

1. **有没有对照组？对照是什么？** 没有对照什么也证明不了。
2. **硬终点还是替代指标？** 硬终点 = 死亡/心梗/卒中/住院；替代指标 = 血糖、血脂、某个 biomarker。能降血糖不等于能减少并发症。
3. **能不能推到我的病人身上？** 看纳入标准。40–60 岁、无合并症、依从性极好的样本，套不到 80 岁多病共存的人。

外推性（generalizability）任何工具都替代不了，必须读者自己判断。

## 四、证据金字塔的写法

从强到弱：系统评价/Meta 分析 → RCT → 队列 → 病例对照 → 横断面 → 病例系列/病例报告 → 专家意见/动物实验/体外实验。

**写的时候必须加两句限定**，否则读者会背成一个死框框：

- 位置不是绝对的：**做得差的 RCT 比做得好的队列研究不可信**。金字塔只是“拿到一个病例报告时该保留多少怀疑”的起点判断。
- **证据等级 ≠ 推荐强度**。前者说结论多可靠，后者说临床上该不该这么做（GRADE 体系，综合利弊、成本、患者意愿）。低等级证据也可能给出强推荐。

## 五、期刊可信度

- **影响因子衡量期刊，不衡量文章**。IF 10 的刊上照样有无人引用的文章；判断文章靠不靠得住只能看研究本身。
- **两套分区不能混用**：JCR 分区（科睿唯安，按 IF 四等分）与中科院分区（学科内 1 区最高）。同一期刊可能一个是 Q1、一个是 2 区，写材料时要注明用的哪套。分区是**学科内相对排名**，跳学科比较毫无意义。
- **掠夺性期刊识别信号**（命中三条以上就该查证）：主动邮件约稿、承诺几天内审完、版面费明显畸高或畸低、刊名蹭名校刊、编委名单查无此人、网站简陋无编辑部信息、在 PubMed 里搜不到该刊任何文章。
- **查证三路**：DOAJ 收录情况、PubMed/MEDLINE 收录、本单位/中科院的预警名单（每年更新，用前务必查最新版）。
- **任何名单都滞后**，最可靠的补充办法：把刊名 + 该刊最近一篇论文标题一起搜，看学术圈有没有公开质疑。

## 六、预印本怎么提

- 价值：快（疫情类抢时间场景）。风险：没过同行评审，方法错误/结论夸大/数据造假都可能没筛过。
- 写法：**可用于了解动向，不能用来支撑结论**。重要结论去查它后来有没有正式发表、发表时数据改了多少。

## 七、来源分层（写之前先分类，别拿记忆写）

| 层 | 内容 | 处理 |
|---|---|---|
| 稳定层 | 证据金字塔、研究类型与证据强度的对应 | 可直接写，注明依据哪套框架 |
| 工具层 | RoB 2 / NOS / AMSTAR 2 / CASP / GRADE | 联网核当前版本 + **附官方链接**（读者可自行核对） |
| 易变层 | 期刊分区、影响因子、预警名单 | **必须实时检索并标日期**，绝不凭记忆写数值 |

查不到权威说法时，明写“业界尚无统一标准”，不自己编规则。
