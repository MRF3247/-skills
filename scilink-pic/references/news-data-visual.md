# 新闻速读卡的数据页（数据带 + 一图看懂）

只在「数字密集稿要加图」时读。栏目规则见 SKILL.md「新闻速读卡 · 数字密集稿」节。

## 一、P1 数据带（三格）

```html
<div class="band">
  <div class="cell"><div class="k">中位总生存</div><div class="v">14.9 <small>vs</small> 12.1</div><div class="s">个月</div></div>
  <div class="cell"><div class="k">死亡风险</div><div class="v">−25%</div><div class="s">HR 0.75</div></div>
  <div class="cell"><div class="k">中位无进展生存</div><div class="v">8.4 <small>vs</small> 5.8</div><div class="s">个月</div></div>
</div>
```

| 元素 | 取值 |
|---|---|
| `.band` | `display:flex; margin-top:22px; border-top/bottom:2px solid #E3E8EF` |
| `.cell` | `flex:1; padding:16px 0 14px; text-align:center`；相邻格 `border-left:1px solid #E3E8EF` |
| `.k` 指标名 | 19px `#6B7787` |
| `.v` 数字 | 38px / weight 900 / `#006EBB`；中间的 `vs` 用 `small` 22px 600 墨色 |
| `.s` 补充 | 18px `#6B7787`（单位或 HR） |

**加带子的顺序**：封面图 `height:900px → 850px` → 加 `.band` → 渲染 → 目视确认 `图片：Pexels / 摄影师` 仍在画面内。`cover-text` 是 `flex:1` + 父层 `overflow:hidden`，超了不会报错，署名会静默消失。实测带子 + 850px 图时内容底到页脚剩 **64px**（合格）。

三格怎么选：优先放**主要终点、风险比/绝对差、次要终点**；同一指标不要拆两格（「14.9」「12.1」各占一格 = 浪费）。

## 二、单独「一图看懂」整页（**已被退回，仅在栏目本身就是图表版时用**）

> 用户看过这一版后明确纠正：「我是说文章的文字里可以穿插一下这种图表来形象化表述，而不是把文字都去掉只放图表」。默认走第五节的**正文穿插图块**；本节保留是因为它的条形几何与归一化算术可直接复用。

1080×1440 单页，天头与正文页同构（左「新闻速读」胶囊 / 右 logo+关键词），页脚只有页码。

```
天头 → h2 52px 900 品牌蓝 → 副标 24px 灰（试验名｜人群）
→ 图例（22px，色块 26×14 圆角3）
→ 每行：左「指标名 30px 700」+ 右「HR 22px 灰」
         下两条：轨道 flex:1 height:50px #F4F8FC 圆角6，填充同高
         数值列 width:150px 右对齐 28px 700（对照组那条用 600 + 灰）
→ 脚注（20px 灰，上边框 2px #E3E8EF）
→ 页脚 70px #004E86 + 页码
```

**归一化（关键）**：每组以自己的较大值为 100%，另一条宽度 = 较小/较大 ×100%（14.9→12.1 是 81.2%；8.4→5.8 是 69.0%；53.8→32.5 是 60.4%；44.0→32.5 是 73.9%）。因为每组尺子不同，**脚注必须写**：

> **读法：每组内部两条相比；不同组之间不要按条长横比。**条形按组内较高者占满版宽。
> 数据取自<机构 + 日期 + 稿件类型>；图为刀客轻研绘制。

**行数与间距的实测标定**（同一批字号下）：

| 行数 | 结果 |
|---|---|
| 3 行（row 56 / bar 54） | 留白 245px，太空，像没排完 |
| 4 行（row 56 / bar 54） | 留白 20px，贴页脚 |
| 4 行（row 44 / bar 50） | 留白 **102px**，合格 |

所以先定行数再调 `row margin-top` 与 `bar height` 两个值，每次重测；**不要靠加第五行**填空白——多一行就多一个指标要解释。

**标题数量词必须与行数一致**：4 行数据写「一图看懂：疗效对比」，不能写「三项终点」。读者会数。

## 三、验收（程序核）

```python
from PIL import Image
import numpy as np
im = Image.open(path).convert('L'); a = np.array(im); H = a.shape[0]
foot = None
for y in range(H-1, 0, -1):            # 从底部找页脚蓝条上沿
    if (a[y] < 90).mean() > 0.5: foot = y
    elif foot and y < foot - 40: break
rows = np.where((a[:foot-10, :] < 120).sum(axis=1) > 5)[0]
print('留白px(逻辑)', ((foot or 0) - rows.max()) // 2)   # 固定高页面目标 60–150
```

逐项过：`留白 60–150px`、标题与行数一致、读法提示在、脚注含来源与「图为刀客轻研绘制」、每行右侧数值与条形宽度能对上（同组两条比例一致）。

## 五、正文穿插图块（定稿形态）

文字页中间夹一张小图：上段文字 → 图 → 下段文字。模板 `templates/news_bilingual.html` 已支持图块，**不要**手改 HTML。

```json
{"img": "file:///tmp/<主题>/chart_v3.png",
 "figcap": "条形长度按各组内较高者占满版宽；数据取自<机构 + 日期 + 稿件类型>；图为刀客轻研绘制。"}
```

- 插在**数字最密那段之后**（例：中位总生存段之后），一张图覆盖 OS / PFS / 生存率 / ORR 等全部核心终点，不要一页插两张。
- 图块**不可切分**：本页放不下时整块推到下一页（干净，不会半张图），但会带来「下一页顶部没有上文」的观感——这属于可接受，交付时不用解释；真正要避免的是**因为图太高而把上一页挤成残句**。
- Chrome 按路径缓存 `file://` 图片：改了图但 JSON 路径没变会截到旧图。每轮改图都**换新文件名**（`chart_v2.png` → `chart_v3.png`）再写进 JSON。

### 图画法（matplotlib，952 逻辑宽 / 2x）

```python
FONT = "/Users/Jin/Library/Fonts/SourceHanSerifSC-SemiBold.otf"
fm.fontManager.addfont(FONT); plt.rcParams["font.family"] = fm.FontProperties(fname=FONT).get_name()
fig, ax = plt.subplots(figsize=(9.52, 3.30), dpi=200)   # → 1904×660，卡面里显示约 952×330
```

布局固定三列：**左标签（14px 墨色，带单位「（月）」/「%」）｜ 条形区（组内归一化，`BAR_MAX=70`，蓝 #006EBB 上、灰 #9AAAB9 下）｜ 右统计量列（12.5px `#6B7787` 右对齐，`HR 0.75` / `差 9.0 个百分点`）**。条形端点标数值（试验组粗墨、对照组灰），`ax.set_xticks([])` 去掉坐标轴，`ax.grid(axis="x")` 只留极淡竖线，图例放右上角 `bbox_to_anchor=(1.0, 1.0)`。

**尺寸标定（实测）**：`figsize` 高 5.35 → 卡面里 535px，独占一页；4.15 → 415px，仍在页顶顶着；**3.30 → 330px 才能稳妥落在文字之间**。改高度后在卡面里跑一遍 `compose_news_card.py`，看 `pages` 与逐页留白，不要只看原图。

**图例必须离开画布上沿（否则缩到卡面里像被裁）**：图例用 `bbox_to_anchor=(1.0, 1.0)` 且 `subplots_adjust(top=0.90)` 时，图例落在 axes 上方的 10% 余量里，字的上沿正好贴着图片第 0 行——原图看上去「完整」，可一旦缩到 952 宽，第一行字就像被切掉半截，用户会直接报「图例被裁切」。固定写法：

```python
plt.subplots_adjust(left=0.28, right=0.995, top=0.80, bottom=0.03)   # top 从 0.90 压到 0.80
ax.legend(loc="lower right", bbox_to_anchor=(1.0, 1.02), ncol=2, frameon=False, borderaxespad=0.0)
# 出图后四周补 12px 白底，兼底任何字形碰边
im = Image.open(raw); canvas = Image.new("RGB", (im.width+24, im.height+24), "white")
canvas.paste(im, (12, 12)); canvas.save(out)
```

验收不看目测，量墨迹：`rows=np.where((a<200).sum(1)>0)[0]`，**`rows.min()` 必须 > 0（实测改后 81），右侧 `cols.max()` 也要离画布右边 ≥20px**。原图合格后再放进卡面，否则缩图会把 1–2px 的边缘误差放大成「被切」。

### 插入后的分页副作用（两个必查）

1. **上一页可能只剩一句残句开头**：图块推页后，前一页以半句结尾。可接受；若用户在意，把插入点上移一段。
2. **末页可能只剩声明一行（留白 >70%）**：图占了约 330px，页数往往跳一页。修法按顺序：① 合并最后两段（把来源/免责并进药物介绍段）；② 从正文删 60–80 字修饰语（首例：「这也是…首个在<癌种>取得阳性结果」的延伸解释、「把两种机制装进同一个分子」的重复叙述）。**不要缩字号、不要缩图高来腾位置。**

### 验收（逐条）

- 图所在页：**图上方有文字、下方也有文字**（否则用户会判「还是把文字换成图了」）。
- 图内小字在手机尺寸可辨（拿 540 宽缩略图看数值与 HR 能否读）。
- 图注含「归一化说明 + 数据来源 + 图为刀客轻研绘制」三项。
- **图例没被裁**：图内图例文字上下有白边（原图第一行墨迹 `y>0`）；缩略图下看不出「字头被切」。
- `overflow_blocks = 0`；末页留白 ≤ 25%。
