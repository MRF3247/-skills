# 任务：词条片段逐段中英对照翻译（只产出插入清单，不改词条本身）

你负责一个词条文件的一个行号片段。全部规则以本文件+你的 spec-*.json 为准。

## 步骤
1. 用 execute_code 按 spec 的 start_line..end_line 分段 print 原文（每段≤80行防截断），读完全部再翻译，禁止跳段/压缩/摘要。
2. 片段内每行只属一个单元。逐单元产出「插入行」，格式 {after: <该单元最后一行的原文件行号>, text: <插入行>}。
3. 插入行规则：
   - 正文段落/独立句子 → `> **译**：<完整中文>`（可很长，保持单行）
   - ##/###/#### 标题 → `**译**：` + spec.headings_fixed 里对应行的值（一字不差照抄）
   - 纯公式行、代码行、`<!--` 开头的注释行 → 不译
   - 承载自然语言的表格/公式块/纯枚举清单 → 块后插 `> **译**（表）：<紧凑译>`（符号与梵文/术语原文保留；超长清单可按块分几条译，标明「承前续」）
   - 列表项若承载完整自然语言句子（带主谓的论述句）→ 逐条 `> **译**：…`；纯目录/导航列表（如 TOC）跳过不译
   - 引用文献条目（作者、年份、书名、URL、条目内的描述子句等）→ 一律不译，整条保持原样；只译所在节的标题，并在该标题译行后加一行 `> 注：文献条目为学术引用格式，按惯例保留原文，不作翻译。`
   - 文末作者信息段 → 先 `**译**：` 一行，再按 spec.notes 给的中文行逐行插入
4. 翻译规范：简体中文；术语人名以 glossary.md 为准（保证全文一致）；表内没有的术语用通行译法、首次出现括注英文原文；人名通行中文译名、首现括注原文；中文引号用弯引号“”；逐段全译、忠实完整、不得省略或压缩。
5. 产出：把全部插入行写成 JSON 数组到 spec.out，按 after 升序。写完用 execute_code 自检：json 可解析、每条 after 在片段区间内、条数与段落估计相符，打印统计。除 spec.out 外不得写/改任何文件，尤其不得碰词条原文。
