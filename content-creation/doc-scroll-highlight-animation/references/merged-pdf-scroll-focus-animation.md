# PDF 滚动浮出动画（设计师侧规格）

用户已定型的风格（2026-09 BioNTech 结直肠癌 II 期终止项目首用）：真 PDF 滚动（不是 HTML 重排版式）、只挑 2 个核心段落、马克笔从头到尾顺序扫（短时长不并发）、段落浮出突出。一镜到底 + 全程 1.000→1.035 线性缓推保证零静止帧。

## 浮出几何（硬算式，别再猜）
- 字号天花板 = 画幅宽 ÷ PDF 栏宽(pt)。例：1920÷532pt=3.61 px/pt → 8pt 正文最大 28.9px；要更大字号必须行拆开重排（破坏「同一块原文」），别提做不到的倍数。
- 正文整页铺满时约 25px——浮出放大不是装饰而是「看得清」的必需，向用户说明这点。
- 二级放大（短语再抬一次）被否决过：一镜到底里多一次抬起就是多一次跳动，默认不做。

## 留白公式（实测踩过的坑）
留白必须按**片尾镜头缩放后**的屏幕宽度算：栏宽 532pt × 3.15px/pt = 1676px，再除以 1.035 相机推近 → 实测约 122px/边。按 stage 坐标算会少 3.5%，实测掉到 92px、投影贴边消失，「浮起感」失败。

## 浮出做法（定稿）
白纸补片盖住原位 → 同一块原文放大抬起 + 投影；背景压到 ~50% 亮度 + 0.8px 轻模糊（仍要能认出是 PDF 原文页）；smoothstep 进 0.5s / 回 0.4s。卡片裁切收到正文栏宽（别多带空白栏），白边 8px。

## 坐标提取（不许眼估）
PyMuPDF `get_text("dict")` 取词级/行级框，`search_for` 复核关键短语；每个裁切框用 `get_text(clip=rect)` 反向读出框内文字自证没夹带别的行。交付 JSON：pt + 300dpi 像素两套坐标 + 笔迹范围（案例：素材/_pdf_scroll_comment_boxes.json）。

## 验收标准（像素级，出片后自己抽帧量）
- 从交付 MP4 抽帧（ffmpeg），不采信渲染端自测 PNG。
- 卡片左右留白 ≥120px、投影可见（卡外侧带亮度比贴卡暗带亮一档）。
- 印章/角标：画幅层固定定位（不挂卡片，免受缩放牵连），四边完整不切，右/下留白 ≥120/150px，不压英文正文。
- 笔迹顺序可验证：分帧统计标记色像素递增（前段=0，后段递增）。
- 帧差：330 帧 0 重复；无 HUD/时间码残留。

## 医学红线（措辞由 med-creator 定稿，画面别自创）
- "numerical imbalance in overall survival" 只能译「总生存出现数值不平衡」，严禁「生存劣势/疫苗组死得多」等归因词（官方同时写了 No new safety signals，画面保留该句灰显）。
- 终止逻辑链必须完整：数值不平衡 + "unlikely to change the efficacy outcome"（继续也改不了疗效结论）→ 终止，单截「建议终止」是断章。
- 试验登记号（BNT122-01 · NCT04486378 类）放卡片右上角供回查；印章内不放小字（13px 压透底正文会打架）。
- enrollment 写「计划入组约 N 人（ESTIMATED）」，别写成实际入组。

## 分工边界
动画本体/导出/帧差校验 = video-designer；浮出坐标 JSON + 示意预览图 + 帧级视觉审 = designer；台词↔画面节拍表先对齐再施工；英文原文动画配中文对照小灰字（34px > 英文 26px，重点词纯加粗不加底色块）。
