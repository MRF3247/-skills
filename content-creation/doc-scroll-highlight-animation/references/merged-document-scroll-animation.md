# 官方文档 → 滚动动画素材与底稿

医学内容视频里「官方原文上屏」是最有说服力的画面形式，这类活反复出现（期刊图滚动放大、网页滚动高亮、PDF 正文滚动浮出）。本技能管：定形态 → 定标注 → 出素材/底稿 → 独立验证 → 归档台账。

## 用户形态偏好（硬要求，不得自由发挥）

1. **直接滚动原始 PDF**，不要用 HTML 复刻官方稿。原 PDF 是权威物证、版式可信可回查；复刻版被打回过（原话大意：素材直接用我之前发的那个 pdf 就可以了）。
2. **只标 1–2 处核心信息**，每处一句话，取舍标准＝台词里最硬的两句实锤（适应症是什么 / 结果是什么）。铺开标 5 段会被判「很难看」。目标句本在文档首屏（如第一段）时开场不滚——停在文档开头原位直接浮出，让证据在第一句台词落画时就在眼前。
3. **强调靠「浮出放大」，不靠多涂颜色**：白纸补片盖住原位 → 同一块原文放大抬起＋投影 → 背景压暗约 45–52% ＋ 0.8px 轻模糊；进入 smoothstep ≈0.5s / 回位 ≈0.4s；全程不切镜头。
4. **标记顺序由总时长决定**：短片（≈11s）同一支笔从头到尾顺序扫；只有长片才允许多处并发。判据：总时长 ÷ 标记处数 ≥ 2s。
5. **英文原文＋中文小灰字对照**：中文比英文大一档（如 34px vs 26px），对照里点出关键术语（单药 / individualized mRNA 之类）——那些术语是中文台词的画面锚点，砍掉高亮后靠它兜住论点。中文行末必须有句号；换行落在自然词界（「结直肠癌」「ctDNA」等关键词组用 nowrap 保护不劈词），括号内容长就拆括号改逗号衔接、别让括号跨行。
6. **一镜到底、零静止帧**：没有分镜；行进感＝下移＋全程线性微推近（1.000→1.035）＋浮出，不靠长滚动。任何完全静止段都会以「重复帧」被抓出来打回。
7. 单页文档只走正文上半页，**别滚页尾免责声明**（boilerplate，滚起来很难看）。
8. **画面只留原文＋标注＋浮出卡**：不加字幕/台词文字（字幕用户自己加；卡内中文对照是卡片内容不是字幕，经确认保留）；不加「官方声明 · PDF 原文」类来源标签角标；正文已自带的信息（如登记号印在正文里）不在卡上重复做角标——回查类信息「画面可见即达标」，不限定位置。

## 流程

1. **拿一手原文并互校**：官网声明 ＋ SEC 6-K/EX-99.1 逐句比对一致才可用。登记页数字走 ClinicalTrials.gov API v2 实查（`curl -s "https://clinicaltrials.gov/api/v2/studies/NCT..."`）；看 `enrollmentInfo.type`——**ESTIMATED 只能写「计划入组约 N 人」，不得写成实际入组**；登记页状态可能滞后于官方声明，终止依据只引官方声明。
2. **医学口径交医学编辑定稿**，不自译结果/安全性措辞。已知红线：`numerical imbalance in overall survival` 只能译「总生存出现数值不平衡」，禁止归因表述；`No new safety signals` 保留不剪（不藏证据）；断章半句（如 `unlikely to change the efficacy outcome`）必须补回，否则「建议终止」缺逻辑链。定稿措辞原文抄进台账供复用。
3. **量坐标**：PyMuPDF 词级取框，每个框用 `page.get_text(clip=rect)` 反向自证框内**只有**目标句；跨行短语拆成逐行独立框。产出 pt ＋ 300dpi 像素两套坐标 JSON。方法与算式见 `references/pdf-scroll-geometry.md`。
4. **出素材**：300dpi 页渲染（`page.get_pixmap(dpi=300)`）、被标段落 600dpi 裁切、浮出卡片底图。
5. **需要交互底稿时做同步网页**：复制 `templates/scroll-sync-min.html` 改内容——它带 stops/cues 两张表、`#t=秒` 确定性跳帧、导出模式、全程微推近。改时长/停留/高亮范围只动这两张表。
6. **验证**（见下）→ 7. **归档台账**。

## 同步网页引擎要点

- **`#t=秒` 必须存在**：滚动位移与高亮状态是 t 的**纯函数**，任意时刻可确定性截帧对位；暴露 `window.__seek(t)` 给无头截帧。
- **导出模式**（`?export=1`）：禁掉所有 CSS transition、把高亮进度改成 t 的纯函数。否则 seek 后立刻截图拍到的是过渡中途态（印章像没落、高亮像半涂＋压字），且逐帧不确定。
- **每个高亮/印章元素真的挂到 cues 分组上**（`data-g`）：漏挂时 `fire()` 静默空转，元素在**任何情况下**都不出现（交互播放也不出现）。交付前自检分组覆盖，别信「表里有条目」。
- 抓帧模式自动隐藏 HUD（时间码会进画面）。
- 推近的 `transform-origin` 落在当前视口中心点，缩放不产生跳变。

## 验证（不许目测，不许采信回执）

- **同房间其他 agent 的成片**：它报「已渲完 / 全帧唯一 / 无音轨」也要自己复跑一遍——回执只是它的判断，磁盘上的文件才是事实。`scripts/verify_video_deliverable.sh <文件>` 一次给出：大小·sha256·时长/分辨率/fps·音轨有无·**全帧降采样哈希的重复帧数**。
- 时长/流信息：`ffmpeg -i x 2>&1 | grep -E "Duration|Stream"`（本机 ffprobe 的选择性参数不可用时的等价做法）。
- **网页底稿**：无头 Chrome `--headless --disable-gpu --hide-scrollbars --window-size=1920,1080 --virtual-time-budget=N --screenshot=out.png "file://…html#t=秒"`，再用 PIL 做像素带统计——高亮色像素数随 t 单调递增＝顺序标记成立；计数为 0 或异常＝该 cue 没触发。
- **同名覆盖重渲后必须重跑**验证并重新钉 hash（`shasum -a 256` 取前 16 位即可人肉核对）；台账里的旧验证数据随即作废，否则档案记录的是已不存在的版本。

## 台账（每批次留 README）

项目素材目录写 `<主题>_素材批次README.md`，含：交付物表（文件·大小·**sha256**·时长/分辨率/fps/音轨/帧数与重复帧数）· v1→v2 改动只列观感项并声明「内容口径零改动」· 施工源路径（页面＋资产目录）· 留档与已退役文件 · 一手来源链接 · 医学红线定稿措辞 · 已关闭事项。

## 坑

- **留白公式要把相机缩放放进分母**：按 stage 坐标算出的留白会比实测多约 3.5%（相机 1.000→1.035 把画面又放大了），要按缩放后的屏幕宽度算。
- **字号天花板**：`1920 ÷ 栏宽(pt) ＝ px/pt 上限`。8pt 正文 / 532pt 栏宽 → 3.61 px/pt ≈ 28.9px，扣边距约 28.3px。想更大只能拆行重排（就不再是「同一块原文」）；「被扫短语 600dpi 单独裁切做二级放大」是唯一合规路子，但短片里多一次抬起＝多一次跳动，通常不做。
- 卡片左右顶死画幅（x=0→1919）时投影看不见，视觉读成「白带」而不是「一张纸」——收裁切、缩白边，保证左右各留白 ≈120px。
- **布局量别从 rect 差值反推**：`getBoundingClientRect` 返回 border-box，`padding-right` 只影响内部文字排版、不移动盒子右缘——算天窗宽这类可用空间要用「布局常量 × 屏幕/布局缩放比」，两个 rect 相减会算出负值。
- 印章别放在会遮正文的位置：落点按**卡片终态几何实时计算**（如骑卡右下空白带），别钉固定 `right/bottom` px——卡片内容增删会改卡片高度，固定值会让印章下坠或切边压到别处；「不遮任何字」是硬标准，验收看终帧。
- 动画底稿被新方向取代后就退役，不要再回头补齐它的 bug——先确认它是施工源还是留档物。

## 边界

- 渲染成片（时间轴、镜头运动、ProRes/VP9 导出）归 video-designer；本技能产出素材、坐标、底稿、验证与台账，不重复渲染管线。
- 终帧装饰性小重叠（如印章掠过行尾）不阻塞交付：是否重渲由内容口径负责人拍板；对应微调参数写成注释留在源文件，日后任何原因重渲时顺手改，不为此单独动哈希。
- 视频下载与 yt-dlp 相关走 `video-material-download`（用户自有技能，勿改）。
