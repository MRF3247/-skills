## schema 要点

- **count**: `[1,2,4]` — 抽卡用 count=2（同提示词出 2 张对比，质量差异常达 2-3 分）
- **ratio**: 小红书用 `3:4`（1242×1656 输出）
- **quality 范围因模型而异**: doubao 只收 `1K/2K`；seedream-4/jimeng 收 `2K/4K`；nebula-ultra 收 `1K/2K/4K`。传错报「不在允许范围」。
- **modeType**: 连了参考图入边必须显式 `-s modeType=image2image`，否则校验报错。

## 插画 prompt 模板（整块插画方案，已验证 8-9 分）

```
竖版海报主视觉插画（3:4），<风格提示词>。画面：<医学科研主体元素>。
画面下方留出约四分之一高度的干净空白区（无任何元素）供排版文字。高细节，无文字
```

关键点：
- 「无文字」必须写，否则引擎会自行添加乱码文字
- 下方留白区要写「干净空白区」，让引擎自动生成可排版区域
- 元素用医学科研主题（医生/白大褂、DNA、显微镜、细胞、樱花/海浪等氛围元素按风格定）
- 风格提示词直接抄视觉风格家谱各家族的「风格提示词（中文）」

## 方法卡背景 prompt 模板

```
竖版知识卡片背景插画（3:4），<风格提示词>。画面：<装饰元素>，中间是干净的<底色>空白区域（约占画面六成，无任何元素）供排版文字。极简构图，大量留白，高细节，无文字
```

## 迭代记录（小红书「找经典文献」海报，2026-08）

- 方案 A（AI 直接生整张含文案海报，seedream-4 图生图）：3.5/10，五步列表丢失、色号乱码 → 弃
- 方案 B（AI 生整张 + 文案内嵌，doubao）：7.5~9.3/10，仍被用户以「丑」否决 → 弃
- 方案 C（抠图元素叠加：rembg / 白底阈值 / multiply）：全部 5/10 上下，抠不干净 → 弃
- **方案 D（整块插画 + HTML 分层排版 + 视觉审核）：8-9.2/10，最终采用**（本 skill 流程）

各风格实测分（封面/方法卡，视觉审核）：浮世绘 8.0/9.2（最佳）、点彩 8.0、3D科技 7.8/8.5、复古科学图鉴 7.5、矢量扁平 7.5、复古拼贴 7.5、水彩 7.5、复古印刷 7.5、包豪斯 6.5、钢笔素描 6.5。

## 内容合规坑

- 提示词含「古典人体雕像」→ 生成的图被 MiniMax 视觉审核判 422 sensitive（小红书平台也会拦）。修正：去掉人体/雕塑描述，换纯医学物件（显微镜/细胞版画/DNA 分子网络/化学器皿）。修复后 7.5/10 合规。
