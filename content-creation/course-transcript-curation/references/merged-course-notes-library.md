# 课程逐字稿 → Obsidian 学习库（+ 得到大脑归档）

用户持续购买运营类网课（小红书/B站/抖音/AI 工具），每门课的交付物固定：Obsidian 里一套四层目录，外加同步到得到大脑「内容运营」库的对应文件夹。已按此法完成多门课（谢无敌小红书、戴小胖小红书电商、安先生个人IP、dbsilent AI小红书运营课）。

## 库结构（固定，勿自创）

```
<课程名>/
  00-导航/        00-索引-XX导航.md（库怎么用 + 推荐阅读路径 + 每篇一句话）+ 总纲-知识地图.md
  01-精华读本/    00_前言与导读.md + 按模块编号的成品手册（跨节去重、重写、纠错）
  02-每节整理/    NN_节名（整理版）.md —— 每节一篇，frontmatter 带 source 回链逐字稿
  03-逐字稿原文/  完整逐字稿 + 每节/ 分节文件（原料层，机器转写，不改动）
```

每个文档末尾挂 `🧭 [[00-索引-XX导航]]` 回导航。三层关系：01 是跨节去重的成品总览，02 是保留原貌可溯源的逐节整理，03 是原料。

## 流程

1. **先盘点再动手**：`find . -type f | sort` + `wc -c` 列出每节字符数；看清 `02-每节整理/` 已有什么（用户常留一篇当范例）、`01-精华读本/` 是否空白、逐字稿分了几节。
2. **歧义先问清再批量**（用户明说「不清楚的可以先跟我聊清楚再做」）：交付范围（补每节整理 / 写精华读本 / 两样都做）、精华读本怎么分篇、是否同步得到大脑。用一次 clarify 问全，别边做边改。
3. **每节整理 → 并行子代理**：7 个并行、每个 2 节；**配对按字符数均衡**（最长节配最短节），让每个子代理的输入量相当。每个子代理的 context 必须自带：逐字稿绝对路径、产出绝对路径、范例文件路径（要求它先 read_file 已有的整理版）、格式模板（见下）、硬性规范（见「子代理规范」）。
4. **精华读本**：等每节整理稿齐了再写，按模块分成 4-6 篇 + `00_前言与导读`；跨节去重合并，不是逐节复制。
5. **00-导航**：索引文件（库怎么用 + 阅读路径 + 每篇一句话简介 + 目录树）+ 总纲知识地图。
6. **同步得到大脑**：见 skill `getnote-cli` 的「本地 Markdown 批量归档进指定知识库文件夹」——`kb directories` 查/建文件夹 → `save`（不带 `--topic-id`）→ `kb add --directory-id` → `kb directories --directory-id` 核对 total。

## 子代理规范（每条都有代价，别省）

- **只依据逐字稿**：明写「绝对不许补充逐字稿里没有的信息/案例/数据/产品名/结论」，看不清处按上下文还原并在「整理说明」标注存疑——课程是口播，品牌名和数字极易被顺手编出来。
- **给专有名词正确写法清单**（Gemini 2.5 Pro / Claude 3.7 Sonnet / DeepSeek R1 / Perplexity / Monica / 腾讯元器 / LobeChat / OpenRouter / Claude Code / Claude Skills…），但要求以逐字稿实际提及为准，别硬塞讲师没讲过的工具。
- **术语/缩写首次出现给全称 + 一句大白话比喻**（用户固定要求，面向完全不懂的人）。
- **宁全勿简**：约 1 万字符/节；讲师给的系统提示词原文、界面操作路径（菜单/按钮名）要完整保留——这才是课程的真正资产。
- **ASR 纠错要留痕**：「整理说明」列出主要错字对照（转写常把 Gemini 写成「郑梦娜/正代」、Monica 写成「莫妮卡/梦妮卡」、Perplexity 写成「proxity/probability」）。
- 子代理**不能提问**：有歧义在派发前问用户。

## Pitfalls

- **每节整理编号 = 课程节序，不等于逐字稿文件名编号**：分节文件常整体偏移（逐字稿从 02 起编号、或跳号），派发前逐条核对映射，否则文件名全错位、导航链接全断。
- **既有整理稿的编号就是基准**：若 `02-每节整理/01_XXX（整理版）.md` 内容对应逐字稿第 02 个文件，则「整理编号 = 逐字稿号 − 1」，顺着推，别重新发明编号体系。
- **子代理自报 ≠ 落盘**：收工后自己 `wc -c` 数文件、抽查开头结尾与关键段落，别只信子代理的总结。
- 大课分阶段交付：每节整理 → 精华读本 → 导航 → 同步，逐阶段汇报，别承诺一次性全交。
- Obsidian 源文件只读，产出一律写新文件。
