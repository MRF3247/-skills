# 医生工作量 / 文书负担 / 倦怠类选题：数据源与口径陷阱

面向「中美医生处境对照」「医生倦怠」「文书负担」这类选题。核心难点不是找不到数字，而是**两国的数字不同口径、不同年份、不同定义**，直接并排就是硬伤。每次现取当年版本，本文件只给源与判法。

## 一、源地图（按权威度排序，先用上面的）

### 中国

| 想问什么 | 用哪个源 | 注意 |
|---|---|---|
| 医生工作量（日均接诊、床日） | 国家卫健委《我国卫生健康事业发展统计公报》年度版（每年 8 月前后发布，省级卫健委站点常有 PDF 直链） | 官方唯一细口径来源；见下方「分母陷阱」 |
| 门诊/住院总量、三级医院占比 | 同上公报 | 三级医院诊疗量占比持续走高，是「患者向大医院集中」的硬证据 |
| 文书要求在松还是紧 | 卫健委《当年国家医疗质量安全改进目标》 | 若「关键诊疗行为相关记录完整率」仍在目标清单里，即记录要求当年仍在加码 |
| 官方对 AI 减负的定调 | 当年基本公共卫生服务通知、为民服务实事通知、「人工智能+医疗卫生」实施意见 | 看是否出现「减轻基层/医务人员负担」表述，这是政策口子 |
| 病历法定时限 | 《病历书写基本规范》（首程、入院记录、首次查房记录的时限） | 这是中国特有的硬约束，美国没有对应物 |
| 医保侧文书负担 | 医保局 DRG/DIP 支付方式改革文件 + 病案首页/结算清单填报规范 | 病案首页错编码直接影响医院收入，压力会下沉到医生 |
| 医生自己怎么想 / AI 使用 | 丁香园×麦肯锡《中国医生 AI 行为与态度调研报告》（年度，主流媒体有转载版） | 商业调研，可用作行为数据，不可当官方统计 |
| 周工时、倦怠率 | 中国医师协会《中国医师执业状况白皮书》 | **已多年未更新**；引用前先确认是否有当年新版，没有就按缺口处理 |

### 美国 / 国际

| 想问什么 | 用哪个源 | 注意 |
|---|---|---|
| 文书占工时比例 | AMA 医生工时研究（Medscape 年度报道会引用） | 常被二手转述成「约 1/3 工时」，引用时标转述链 |
| 医生压力/倦怠年度趋势 | Medscape 年度报告 + The Physicians Foundation 年度 Survey of America's Physicians（两者合做，n≈1000，每年 9 月发布） | 同一调查常按执业形态分层（受雇 vs 独立执业），这组分层最有选题价值 |
| 全球对照 | Elsevier Clinician of the Future（年度） | 全球口径，用于「全球同病」类论断 |

## 二、口径陷阱（最容易翻车的地方）

1. **「医师日均担负诊疗人次」是全院分母**。住院医师、手术医师、行政岗都算在分母里，所以这个数远低于门诊医生真实日接诊量。用它论证「门诊强度」是错配；门诊强度要么看单院实测研究（门诊平均就诊时长），要么看具体科室数据。基层口径反而最高（社区卫生服务中心常明显高于医院均值），说明基层医生才是接诊最密集的一群。
2. **官方公报里的相邻百分比可能属于完全不同的题目**。例：某年度调查页面同时出现「58% 经历过致衰压力」和「78% 认为存在心理疾病污名」，78% 不是倦怠率。抄数字前必须读它归属的那一句，不要按页面位置归属。
3. **中国没有「文书占工时 X%」的官方同口径统计**。美国有（AMA），中国没有。写对照时这一格只能写「无同口径数据」，用「工作量 + 政策方向」替代，不许拿别的比例硬凑。
4. **「一天看上百个病人」是媒体/口述口径**，不是统计口径；能用的官方替代是公报工作量与单院实测门诊时长。
5. **政策文件「提高记录完整率」≠「增加文书量」**，但可以据此说「文书要求在当年没有放松」。陈述强度要卡准。

## 三、官方公报 PDF 的取与验

`nhc.gov.cn` 政策页不少是 JS 渲染，`curl` 可能只回几十字节（等于抓空）。可靠路径：

1. 直接找**公报 PDF**——省级卫健委、健康报等常转发带直链的同一 PDF。
2. 下载后用 PyMuPDF 抽文本核数：`python3 -c "import fitz; d=fitz.open('gb.pdf'); print(''.join(p.get_text() for p in d))"`。
   - 系统 `pdftotext` 可能抽不出中文（管道里静默返回空），PyMuPDF 更稳。
3. 用 `re.finditer` 定位关键句（如「日均担负诊疗」），连上下文一起打印——表格前后往往写着 2024/2025 两年对照值，一并取走，比只抓当年一个数更有用。

## 四、交付形状

- 先给结论句（同/不同在哪一层），再上对照表，表里**每个数字标年份与口径**。
- 单列「查不到的」一栏并写原因——用户要求「查不到标注原因」。
- 出处清单每条附一句「它支撑哪个数字」，全部落在当年，末尾声明剔除了哪些旧资料。
- 数据缺口本身是结论：例如「某国官方不测倦怠、只测工作量」就是选题里最值钱的一句。
