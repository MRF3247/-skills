# 留白风格：分析管线 + AI 生图留白优化（2026-08-07）

来源：用户 Billfish 收藏 19 张「留白很好看」的海报 → kimicode k3-256k 逐张纯视觉分析 → 沉淀为排版参考库《排版学习笔记_留白风格.md》（Obsidian，含 19 原图 + 留白六律 + 每张可复用 AI 生图提示词）。

## 留白六律（19 张海报提炼，prompt 可直接引用）

1. **大面积单色负空间**：留白不是空白，而是大面积纯色/微肌理区域，占画面 40-60%
2. **主体偏心构图**：主体靠边/偏一侧，留白集中在另一侧或对角
3. **留白区域有呼吸点**：纯色区放细小元素（小字、小标、微纹理）避免死板
4. **排版呼应留白**：字距行距宽松、对齐错位、元素间距与留白成比例
5. **颜色对比制造留白感**：高饱和主体 × 低饱和/纯色背景，或黑白 × 单色
6. **气质统一**：极简、文艺、高级、治愈——留白是气质不是技巧

## 分析 prompt 模板（k3-256k，每张图）

```
【只分析视觉风格，不读图里文字内容】这是一张留白很出色的海报。请从视觉角度深度分析它的留白技巧：
1) 留白位置与比例（上下左右哪个方向留白多、约占画面百分比）
2) 主体与留白的关系（主体位置、是否靠边/居中、负空间如何衬托主体）
3) 留白区域的性质（纯色/渐变/肌理？留白处有没有细微元素）
4) 排版如何利用留白（元素间距、行距、对齐方式与留白的关系）
5) 整体视觉气质（极简/文艺/高级/治愈？）
6) 可复用的 AI 生图提示词（中文，直接可用的描述，含配色/构图/留白比例）
输出格式：紧凑的 markdown，每项一行，提示词单独一行【提示词】开头。总字数300字内。
```
- max_tokens 至少 1200（800 会截断导致缺【提示词】行——本会话实测第一张 139 字被截断，重跑 361 字完整）

## 给用户封面图做留白优化（无字背景层）

场景：用户拿现有封面插画说「优化留白，方便我打字，生成无文字的封面背景」。先诊断原图（kimi 分析留白分布/元素密集区/适合放字区域），再按留白六律生成。

诊断要点（kimi 输出样例）：主体密集区位置、留白方向与占比、平台 UI 遮挡风险（小红书信息流底部常被标题栏/点赞按钮占用，底部留白会被浪费——顶部留白更值钱）。

生成 prompt 结构（本会话 S3 封面实测 37-44/50）：
```
对这张医学插画封面进行构图优化，只改变布局、不改变画风：
1) 保留<风格锚点：媒介/配色/元素清单>；2) 保留原有元素：<逐项列出>；
3) 将所有主体元素整体缩小并下移至画面下部40%区域，元素不再延伸到顶部；
4) 画面上方25%-30%留出完全干净的<底色>留白区，无任何元素、无纹理，
   与画面同色系自然渐变过渡，留白区色彩纯净均匀、适合后期叠加标题文字；
5) 画面整体留白充足、呼吸感强，遵循极简高级留白美学；
6) 画面中不得出现任何文字、字母、数字、水印。
```

引擎选择：
- libtv doubao-seedream（图生图 `-s modeType=image2image --left <参考图> --prompt ... --run`）——能参考原图，最理想
- **libtv 报 1200000136 算力不足 = 积分不够 → 切 MiniMax image-01（image_generate 工具）文生图**：不能图生图，但用详细提示词重绘同风格（风格锚点写全：媒介/配色/元素/留白要求）效果接近；生成后 kimi 视觉评分对比择优

评分维度：留白充足度 /10、可加字性 /10、风格还原度 /10、无文字乱码 /10。两版对比选风格还原更好的一版。
