# 构图 / 封面公式 / 杂志化词汇表（libtv prompt 直接可用）

来源：排版参考库（Obsidian 视觉风格参考/排版参考/）笔记 8/10/11 号浓缩。
用途：写 libtv 生图 prompt 时直接引用构图词与封面公式，提升画面专业度。

## 14 种构图（中英对照，prompt 可直接写英文）

| # | 构图 | 英文 | 特点 / 用途 |
|---|------|------|------------|
| 1 | 中心构图 | center composition | 主体居中成视觉焦点；重点突出，但易呆板 |
| 2 | 对称构图 | symmetric composition | 中轴线镜像；稳定庄重大气 |
| 3 | 三分构图 | rule of thirds | 九宫格交叉点放主体；平衡有层次、引导视线 |
| 4 | 对角线构图 | diagonal composition | 主体沿对角线；动感延伸、打破四平八稳 |
| 5 | S 型构图 | S-curve composition | 沿 S 形曲线排列；优雅流畅有韵律 |
| 6 | 放射状构图 | radial composition | 中心向外放射；冲击力强、聚焦中心 |
| 7 | 三角形构图 | triangle composition | 三视觉点成三角；稳定且有动感 |
| 8 | 框架构图 | frame composition | 前景框架（门/窗/拱）框住主体；纵深聚焦 |
| 9 | 散点构图 | scattered composition | 元素分散；自由活泼生活感，易散乱 |
| 10 | 满版构图 | full-bleed composition | 元素铺满画面；信息量大，易拥挤 |
| 11 | 引导线构图 | leading lines composition | 线条（道路/光线）引向主体；方向感故事性 |
| 12 | 留白构图 | negative space / minimalist | 大量留白主体小面积；高级感，承载少 |
| 13 | 对比构图 | contrast composition | 大小/明暗/色彩/疏密对比突出主体；张力强 |
| 14 | 重复构图 | repetition pattern | 相同元素重复排列；节奏秩序感，易单调 |

用法示例（prompt 片段）：
- `center composition, subject at the center, strong focal point`
- `diagonal composition, subject along the diagonal, dynamic energy`
- `leading lines composition, path guiding eyes to the subject`

## 封面 3 公式（万赞封面收集笔记）

1. **场景带入 + 真实冲击感**：真实场景（办公桌/教室/街头）降低距离感；「沉浸式体验」叙述
2. **真人 + 强人感标签**：真人 C 位占比 50-70%、正面怼脸、情绪直给；强观点短句标题
3. **目标人群 + 痛点/反常识**：反常识标题制造认知冲突（「成绩越好混得越差」）

痛点视觉化公式：强观点标题 + 极端情绪表情 + 高饱和色彩 + 怼脸特写 = 3 秒抓眼钩子
字体：粗黑体/综艺体变体、大字重、字距紧、单字放大错落、关键情绪字变色、双层描边

## 知识卡片排版（构图教学卡笔记，方法卡直接用）

- 标题色块托底（长度刚好覆盖标题=克制）
- 「定义:/优点:/缺点:」标签前置 + 短句
- 左案例 + 右示意图 = 教学黄金组合
- 示意图极简化（圆/方/三角讲清概念）
- 主色重复使用建立品牌感；纸纹背景提升质感；留白 ≥30%

## 视觉杂志化（每个故事都有自己的方向笔记）

- 标题即故事：场景升维三步法 = 具象场景 → 提炼动作 → 抽象哲理
  （例：火车/铁轨 → 「各自的奔赴」 → 人生方向的隐喻）
- 冷色场景 + 暖色文字 = 最统一的视觉语言
- 杂志通用语汇：日期戳 / 栏目标签 / @符号 / 小箭头 → 编辑感而非广告感
- 错位排版：不绝对对齐、轻微溢出边框，营造「被阅读」感
- 多字体系统：中文粗体 + 英文衬线副标 + 手写体点缀

## 基础配色 6 法（巧用基础配色笔记，prompt 配色词汇）

口诀：同色系稳妥，相邻色柔和，互补色抢眼，黑白灰加亮色基本不会出错。
1. **同色系**：取 1 主色（可从画面最抢眼的颜色里选）→ 不同深浅搭一组 → 安全有层次，适合文艺风/高级感
2. **相邻色**：色相环上紧挨的 2-3 色 → 和谐不刺眼，适合温馨/自然主题
3. **互补色**：色相环 180° 两端 → 最醒目，但**控制比例分主次，千万别五五开**
4. **RGB 基础互补**：红↔青、绿↔品红、蓝↔黄（蓝黄组合最常见）
5. **黑白灰加亮色**：万能公式，一抹亮色点睛
6. **生活取色**：从参考图/实景直接取色，比凭空想强百倍（Pinterest 素材+家谱样张就是取色库）
prompt 用法：`color palette: monochromatic teal shades` / `complementary blue and yellow, yellow as dominant accent (~10%)`

## 网感封面公式（网感视频封面攻略笔记）

黄金公式（人像压底 + 文字浮顶）：
`大标题（黑黄撞色，上方）→ 人像（特写+夸张表情=情绪锚点，中部）→ 结果承诺（黄色高亮，下方）→ 角标（免费/教程，角落）`
- 提问标题击中痛点 + 结果话术（「一次性说明白」「三分钟拿捏」）+ 数字亮色突出
- 撞色组合：黑底黄字=干货/方法论/清单；红字+蓝描边=揭秘/避雷；纯色字+同色系重描边=复杂背景可读
- 装饰密度：3-5 个元素（1 箭头 + 2 emoji + 1 角标），角隅点缀而非堆砌
- 信息降噪：一张封面只承载 1-2 个核心信息，色彩/字体/贴纸承担 90% 视觉吸引力

## 系列超级符号色（春日海报住在自然系列笔记）

- **1 色贯穿全套**：9 张海报只用 1 个品牌色（电光黄），承担标题/信息/装饰全部功能——系列设计与其用 5 种颜色，不如 1 种颜色贯穿
- 配色配比参考：主色 ≈25%（文字+装饰）＋ 背景色 ≈60% ＋ 点缀/留白 ≈15%
- 让文字「长」在照片里：字与人物/山体/树产生空间关系，不浮在边缘（同文字穿插）
- 情绪文案公式：中文金句（最大）+ 英文意译（装饰层）+ 实用信息（最小脚注）
- 地图/坐标/轨迹导游感：路线图、海拔标记、距离刻度直接画在照片上 → 旅行手帐/探险手册感
