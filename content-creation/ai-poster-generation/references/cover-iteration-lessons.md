# 封面迭代教训（2026-08-07 · C 封面文献检索主题 v2→v5 全过程）

用户要求按 Nature/Cell 期刊封面风格做封面，主题「找经典文献不用瞎翻，科研人给你私藏的检索技巧」。
五轮迭代完整复盘——**「机器审图高分 ≠ 用户满意」是本会话最大的认知差**。

## 核心教训

### 1. 用户不满意时：让用户给「觉得对」的样张，kimi 倒推，不要自己反复重写 prompt
- 用户原话：「你让kimi根据这张图来生成提示词」——用户手里有自己满意的参考（可能是自己收藏或别人做的），这是最高质量的风格锚。
- 路径：用户给图 → kimi_see.py 倒推（画风流派/配色/构图/元素清单/质感/适用主题，prompt 要求「300字以上详细描述」）→ 把倒推结果写成生图 prompt → 生成。
- 效果：v4/v5 风格还原度直接从「0 关系」跳到 8-9/10。
- 倒推 prompt 的要素：画风流派（如「现代扁平矢量插画，Corporate Memphis 简化+编辑插画」）、具体色值区间（如「皇家蓝 #0B3D91~#1447A6」）、构图（主体位置/动线/环绕）、元素清单、质感（矢量平涂/边缘锐利/极少量噪点）、适用主题。

### 2. 审图必须用「挑剔模式」，默认审图会虚高
- kimi/MiniMax 默认审图偏宽松：v2 审 9.1/10，用户实际「好丑」。
- 挑剔审图 prompt 模板：「用挑剔的审美眼光」「直说，不要客套」「与顶级期刊封面（Cell/Nature）相比差在哪里」「逐维打分（概念/构图/配色/质感/留白）」。v3 用挑剔模式审出 5.7/10，与用户观感一致。
- 审图维度要加「概念是否老套/有无记忆点」「构图有无张力/是否图库级」「配色是否安全到无聊」「留白是设计还是没画」——这些是宽松审图不会暴露的。
- **机器分是参考，用户观感是终审**：出图先给用户看，用户说 OK 才归档。

### 3. 「单一强概念」vs「元素拼盘」（Nature/Cell 封面语言）
- 元素拼盘（v2：放大镜+报纸+靶心+卡片+箭头）= iconfont 素材页截图，五个弱概念没有叙事关系。
- 顶级期刊封面 = **一个强视觉隐喻讲到底**（如「一摞文献中精准聚焦那一本」），有智力含量。
- 概念要避免图库素材的用烂组合（放大镜+书堆=搜索，是 stock illustration 的老梗）；要么靠实验图像震撼、要么靠大胆概念隐喻。
- 构图要有焦点、敢于不平衡（Cell/Nature 常有大胆留白或大胆满版），四角对称填空是最偷懒的构图。
- 配色要有主张：安全配色（企业蓝渐变）= 没有记忆点。蓝橙互补、高饱和撞色、暗底+亮色是期刊封面常见主张。

### 4. 留白区颜色跟随主底色，不是固定白色/米白
- 深蓝主底风格（S4 类）：顶部留白必须纯深蓝（白字标题），米白留白 = 割裂「像横幅贴上去」。
- 米白/浅色主底风格：顶部留白用米白/同色系渐变。
- 规则：留白区与整幅底色完全一致（prompt 写「纯深蓝（与整幅底色完全一致的皇家蓝）干净留白区」），标题文字颜色由底色决定（深底白字/浅底深字）。

### 5. 机器审图的「无文字」≠ 用户要的「无文字」
- 用户要的是「无文字背景层供自己后期打字」，不是「抽象横线色块伪装文字」。
- v4/v5 中图纸张/书页上的「伪文字线条」被 kimi 评为聪明处理，但用户要打字时这些线条可能干扰——如用户后续反馈，可在 prompt 加强「纸张上只保留版式空白，无任何线条暗示」。
