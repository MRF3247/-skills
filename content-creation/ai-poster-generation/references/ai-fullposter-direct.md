# AI 直出带文案整图（2026-08-06 实测）

用户最终路线判定：**不要 HTML 分层排版，要 AI 生图引擎直接生成「设计+排版一体」的带文案整图**。
本文件记录实测结论、失败证据与就绪脚本，避免重复踩坑。

## 铁律：MiniMax image-01 不能用于带中文文案整图

**实测 2 次（2026-08-06），结论一致：中文长文案必乱码（伪汉字 glyph hallucination）。**

- 试 1（完整文案入提示词）：插画 8.5/10（浮世绘浪花到位），中文全部变成不可读伪汉字，文字 1/10，总分 4.5
- 试 2（文字区域隔离 + 短文案 + "文字必须正确"强调）：同样乱码，英文还出现拼写错误（AIMLESSLY→AIMMEESLESN），总分 3.5
- 结论：这是 image-01 模型的中文文字渲染能力缺陷，**不是提示词能救的**。提示词再怎么强调"字必须正确无错别字"都无效。

**正确选型**：
- 带中文文案整图 → libtv doubao-seedream-5-0-pro（中文排版最强，历史实测中文文案 10/10）
- MiniMax image-01 → 只用于无字插画或英文短文案
- 测试图归档：`成品_v5/AI直出测试_MiniMax/封面_试1_乱码.jpg`、`封面_试2_乱码.jpg`（备查）

比中文准确度 + 画风，谁好谁做主力。查询命令：`libtv model search <关键词>`。

## libtv 积分耗尽的判断模式

用户说"libtv 今天没积分了明天才刷新"。实测验证方法：

- `libtv node create` 会成功返回 nodeKey（节点创建成功 ≠ 生成执行成功）
- 但 `libtv node <名>` 查询 `data.url[]` 恒为空数组，等 90 秒+仍空 → 生成不执行 = 积分/额度耗尽
- 判定后立即 `libtv node delete` 清理测试节点，避免污染画布
- 积分刷新周期：按天（用户账号 进阶版VIP 连续包年）

## 就绪脚本：gen_ai_fullposter.py

位置：`工作资料/小红书示例笔记/libtv生成/gen_ai_fullposter.py`
（libtv 积分刷新后直接运行，先做 S1 浮世绘套的封面+第一步两张）

内容要点：
- 引擎：Seedream 5.0 Pro（doubao-seedream-5-0-pro）
- 浮世绘风格基座取自视觉风格家谱 01（青绿巨浪/珊瑚橙圆点/米白和纸/樱花/DNA/白大褂医生）
- **排版气质（2026-08-06 定稿）：A+B+C 混合**——标题超大衬线大字（冲击力，杂志/网感派）+ 大量留白呼吸感（文艺派）+ 手写涂鸦点缀（圈/箭头/星点，活人感派）。这是用户投喂的 19 份排版参考里出现最多的组合，也是 v5 HTML 验证过的方向（标题阶梯错落/徽章贴纸感/留白克制），翻译成提示词 `DESIGN_LANG` 段落：标题两行错落、row2 右缩进、5步法徽章 rotate(-6deg) 贴纸感、副标小字、角落手绘涂鸦、文字与画面同色系融合、禁止独立白底文字框。clarify 未获响应时按此最优判断执行。
- 封面文案（严格沿用参考图 _1）：「找经典文献」「不用瞎翻」「科研人私藏检索技巧」
- 第一步方法卡文案（严格沿用参考图 _2，OCR 提取全文）：
  - 标题「第一步：锁定领域「奠基性核心文献」」
  - 「不要上来就搜最新研究，先找领域的「开山之作」」
  - 「操作方法：用Web of Science/知网搜索关键词，按「被引频次从高到低」排序」
  - 「前10篇基本都是公认的经典，哪怕10年前也一定要读——是整个领域的研究基础」
  - 「重点看：研究问题、核心结论、局限性，后面90%的研究都在这个框架上延伸」
- 用法：`python3 gen_ai_fullposter.py 1 2`（1=封面 2=第一步）
- 生成后仍走标准流程：无水印下载（fetch_originals.py 方式）→ MiniMax 视觉评分 → 抽卡选优 → 复盘提示词
