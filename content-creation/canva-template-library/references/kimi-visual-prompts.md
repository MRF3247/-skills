# kimi 视觉分析 Prompt 模板（kimicode k3-256k）

## 通用参数
- 端点: `https://api.kimi.com/coding/v1/chat/completions`
- 模型: `k3-256k`（视觉分析/提示词倒推首选；256K 上下文内效果同 k3 且消耗减半）
- **max_tokens ≥ 1200**（800 会截断，导致输出缺字段如【提示词】行）
- 图片: base64 data URL，thumbnail 到 max_side=1024、JPEG quality=80（2484×3312 原图 base64 会超 shell 参数限制）
- 批量调用偶发空返回 → 断点续传 JSON + 重跑缺失项

## 场景 1：主题适配筛选（医学/论文/学术）

```
【只看视觉风格，不读图里任何文字】判断这张图的视觉风格是否适合一个「医学/论文/学术」主题的内容账号使用。
从视觉元素判断（不看文字内容）——适合的视觉特征：医学插画/解剖图/细胞分子图形、DNA/基因/科研图标、
科学图表/数据可视化风格、学术海报版式、复古医学图谱、实验室/手术/显微镜场景、专业科研摄影、
极简专业排版、学术期刊封面气质（庄重/理性/专业配色）。
不适合的视觉特征：纯风景/旅行照片、美食餐饮摄影、美妆时尚穿搭、卡通萌宠、娱乐拼贴、
婚礼派对庆典、运动健身、儿童启蒙涂鸦等与医学学术无关的视觉题材。
判断标准：视觉上能否承载医学/论文/学术内容（通用但专业克制的风格也算适合）。
只输出 JSON：{"suitable": true或false, "reason": "一句话视觉理由（30字内）"}
```

解析注意：模型可能输出杂讯，用正则 `\{[^{}]*"suitable"[^{}]*\}` 提取 JSON。

## 场景 2：留白海报深度分析（排版参考笔记）

```
【只分析视觉风格，不读图里文字内容】这是一张留白很出色的海报。请从视觉角度深度分析它的留白技巧：
1) 留白位置与比例（上下左右哪个方向留白多、约占画面百分比）
2) 主体与留白的关系（主体位置、是否靠边/居中、负空间如何衬托主体）
3) 留白区域的性质（纯色/渐变/肌理？留白处有没有细微元素）
4) 排版如何利用留白（元素间距、行距、对齐方式与留白的关系）
5) 整体视觉气质（极简/文艺/高级/治愈？）
6) 可复用的 AI 生图提示词（中文，直接可用的描述，含配色/构图/留白比例）
输出格式：紧凑的 markdown，每项一行，提示词单独一行【提示词】开头。总字数300字内。
```

## 场景 3：参考图倒推提示词（风格溯源）

```
你是视觉风格分析专家。分析这张图片的视觉风格，输出【仅一行】精炼的中文风格提示词，
格式模仿：浮世绘木刻版画风格，浮世绘配色，柔和暖色调与冷色调，复古纸张质感，
衬线字体，期刊封面布局，高细节。
要求：只描述美术视觉风格（风格流派、配色、质感媒介、构图、字体、时代气质），不写具体内容。
```

k3 会溯源到具体画家/作品/技法（如歌川广重《名所江户百景》、Didone 衬线体、bokashi 晕染渐变），
质量远超 MiniMax-M3（模板化）和 k2.5（结构完整但浅）。

## 其他教训
- kimi-k2.5 可 `thinking:{type:disabled}` 秒回，适合日常审图（诚实、批评具体，但偏严格）
- MiniMax-M3 会幻觉（把乱码脑补成通顺词、编造不存在的细节）→ 只作交叉验证第二意见
- kimi-k3/k2.6 thinking always on，几千 token 全被思考吃掉 finish_reason=length → 不适合日常
