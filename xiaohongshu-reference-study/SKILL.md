# 小红书排版参考链接学习沉淀流水线

用户会持续发小红书笔记链接作为「排版参考/审美参考/封面参考」，要求逐条学习沉淀到 Obsidian。
2026-08-06 实测跑通 19 条，方法稳定。目标产物：每链接一份学习笔记 + 原图样张 + 索引更新。

## 目标位置（固定）

- 笔记目录：`/Users/Jin/Documents/医时知识库/视觉风格参考/排版参考/`
- 样张子目录：`排版参考/样张/`

## 步骤

1. **抓取**：`browser_navigate` 打开完整链接（必须带 xsec_token；裸 id 未登录打不开）。
   - 正文在页面 snapshot 的 `- text:` 行里（JSON-LD 的 description 常被截断/只有标签，以 snapshot 文本为准）。
   - 图片 URL：`browser_console` 执行 `document.querySelector('script[type="application/ld+json"]')` 解析 `d.image` 数组。
2. **下载样张**：URL 形如 `http://sns-webpic-qc.xhscdn.com/...!nd_dft_wlteh_jpg_3`，**必须 http→https 再 curl**（`${u/http/https}`），否则下载失败。命名 `样张/<主题前缀>_NN.jpg`（如 `牛马宇宙_01.jpg`、`旅行封面_01.jpg`）。
3. **读字**：文字密集图（提示词截图/梗图文案/教学卡）用 macOS Vision OCR，比 MiniMax 转录准。分工：OCR 读字、MiniMax 看审美。脚本已固化在 skill 内：`swift scripts/ocr_vision.swift <图>`（zh-Hans+en-US，accurate 默认，可传 fast；含 y 降序排序输出）。
4. **看审美**：`vision_analyze`（MiniMax）逐张或挑重点图拆解（版式/字体/配色/可学点），提问要具体。
5. **写笔记**：`排版学习笔记_<主题>.md`，结构固定：
   - frontmatter：title / author / source(原链接) / tags(含 医学科研海报) / created
   - 正文要点（作者原话或 OCR 转录，注明来源）
   - 逐图拆解（重点图细拆）
   - 「对医学科研海报的借鉴」一节（必须写，用户要能落地的迁移）
   - 样张网格（见下）

## 【用户硬性要求】每份笔记必须附原图

用户原话：「你的这些排版参考学习笔记里都要附上原图」。用 HTML 网格，不用 markdown 图：

```html
<div style="display:flex;flex-wrap:wrap">
<img src="样张/前缀_01.jpg" width="180" style="margin:3px;border-radius:6px"/>
...
</div>
```

- 图多（10+ 张）用 170-180px；图少（2-6 张）可用 240px 或右浮动 `align="right" width="260"`。
- 不要用 `![[xxx.jpg|180]]`（Obsidian 表格里竖线会被切开；非表格场景 wikilink 可以，但网格统一用 `<img>`）。

## 本地素材投喂（Billfish 收藏，2026-08-07）

用户除小红书链接外，也会从 **Billfish 素材库投喂本地图**（如「留白好看的海报」）要求分析沉淀。Billfish 素材库定位：`~/Library/Application Support/Billfish/config/recent_lib.ini` 的 `CustomSettingLibPath`（本机 = `/Users/Jin/Documents/本地资源库/`，刚下载的图在 `浏览器采集/` 子目录，文件名如 `收藏到 Poster_xxx.jpg`）。流程与链接版同：逐张 kimi 分析 → 复制原图到 `排版参考/样张/留白风格_NN.jpg` → 写 `排版学习笔记_<主题>.md`（原图网格 + 逐张分析 + 提示词速查 + 技巧总纲）→ 更新 00_索引.md。

- **kimi 分析 prompt 要点**：海报风格分析只描述视觉（留白位置比例/主体关系/负空间性质/排版利用/气质 + 一句可直接用的【提示词】），不读图内文字（用户纠正：「从视觉风格的角度来分析，不是说让你提取文字」）。
- **max_tokens 截断坑**：k3-256k 分析输出被截断（症状：字数偏短如 139 字、缺【提示词】行）——max_tokens 从 800 提到 1200 后重跑即完整（361 字）。批量分析完必须校验每份都有【提示词】行，缺的重跑。
- 单张约 30-60s，19 张后台约 15-20 分钟；分析文件按 `NN_原文件名.md` 落 `/tmp/留白分析/`，汇总脚本负责复制原图（**去掉序号前缀 `^\d+_` 再拼源路径**，否则 `00_收藏到 Poster.jpg.jpg` 找不到）+ 拼笔记。

## 经验与坑

- 正文常含作者自己的方法论原文（「14 种构图」「6 种配色」「封面 3 公式」）——优先转录原文，再拆图印证。
- **纯图合集型笔记**（正文只有「仅供欣赏/非原创」，如 18 图电影海报合集）：价值全在图上，正文无方法论可抄——逐张/挑重点图拆解后**跨图提炼通用设计语言**（如「形式即内容/文字与图像互侵/字体对比」），笔记结构改为「重点图拆解 + 跨图共性提炼 + 借鉴」。
- 评论区也常有干货（作者回复的字体拆解等），snapshot 能看到，值得抄进笔记。
- 单条完整耗时约 3-5 分钟（抓取+下载+OCR 2-4 张+MiniMax 1-2 张+写笔记+索引），串行处理即可。
- MiniMax 有 422 敏感拦截风险，解剖/人体类参考图注意。
- 用户偏好「大白话+生活化」拆解，笔记里对术语做医学类比，区分实锤/推断。
- **用户分批给意见模式**：用户会连续发多条参考链接并陆续给审美反馈（「先记着、先不改图、等意见说完」）。沉淀照做，但收齐意见前不要动海报/生图——改图需用户明确授权。
